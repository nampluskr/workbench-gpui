## 2. 정확성 리뷰 (Code Reading)

### 2.1 `top_level_nodes` 탐색 및 경계 조건
- `top_level_nodes(root, window)` 구현:
  ```rust
  fn top_level_nodes<'t>(root: Node<'t>, window: &Range<usize>) -> Vec<Node<'t>> {
      let mut nodes = Vec::new();
      let mut walker = root.walk();
      if walker.goto_first_child_for_byte(window.start).is_some() {
          loop {
              let node = walker.node();
              if node.start_byte() > window.end { break; }
              nodes.push(node);
              if !walker.goto_next_sibling() { break; }
          }
      }
      if nodes.is_empty() { nodes.push(root); }
      nodes
  }
  ```
- **바뀐 범위 경계**:
  - `window.start`가 노드 경계나 노드 내부, 또는 앞 공백에 걸칠 때 `goto_first_child_for_byte(window.start)`는 `end_byte >= window.start`인 첫 최상위 노드를 정확히 선택함.
  - `loop`를 통해 `node.start_byte() > window.end`가 될 때까지 연속된 형제 노드를 탐색하므로, 바뀐 범위에 걸치는 모든 최상위 노드가 누락 없이 수집됨.
- **빈 파일 및 자식 없는 루트**:
  - 텍스트가 비어 있거나 최상위 노드가 없는 경우 `goto_first_child_for_byte`가 `None`을 반환하여 `nodes`가 비게 됨.
  - `if nodes.is_empty() { nodes.push(root); }` 분기가 보장되어 있어 빈 파일이나 단일 루트 상태에서도 패닉이나 누락 없이 `root`로 안전하게 폴백함.
- **여러 변경 범위**:
  - `refresh`에서 `for range in changed` 루프를 돌며 각 변경 범위마다 `window`를 생성하여 `top_level_nodes`를 호출하므로, 분절된 여러 편집 범위에 대해서도 빠짐없이 최상위 노드를 탐색함.

### 2.2 중복 주입 방지
- `refresh` 함수 상단에서 단일 `seen: HashSet<(usize, usize, usize)>` (`(pattern_index, first.start_byte, last.end_byte)`)를 생성함.
- 여러 `changed` 범위 또는 여러 `top` 노드에서 동일한 주입 패턴 및 범위를 감지하더라도 `!seen.insert(...)` 검사로 즉시 스킵됨.
- 후보 계층 생성 후 `layer.children.iter().any(...)` 검사 및 `combined` 후보 정렬·`dedup`을 거쳐 동일한 주입 층이 중복 생성되는 현상이 완벽히 방지됨.
