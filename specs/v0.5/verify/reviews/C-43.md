## 3. 코드 정확성 리뷰 (Code Reading)

### 3.1 `src/ui/syntax.rs` (언어 로더, 층위 주입, 아웃라인, 슬롯 수명, 코드 블록 하이라이터)
- **로더 및 쿼리 캐싱**: `OnceLock<QueryResources>`를 통해 싱글톤으로 로드하며, 디렉터리 부재 시 에러를 수집하고 graceful하게 plain-text fallback을 제공함. 패닉 유발 지점 없음.
- **다중 층위 주입 (Layer Injections)**: `MAX_LAYER_DEPTH = 6` 상한을 두어 상호 재귀적 주입(HTML -> JS -> Regex/JSDoc 등)에 의한 무한 루프를 방지함. `combined` 주입의 경우 줄바꿈(`\n`)을 삽입하여 offset 매핑 일관성을 유지함.
- **증분 파싱 전파 (Incremental Edits)**: `edit(&InputEdit)` 호출 시 각 레이어의 바이트 범위에 오프셋 델타를 정확히 반영하며, 변경 구간과 겹치지 않는 외부 레이어는 이전 트리를 재사용함.
- **아웃라인 심볼 추출 (`symbols_at`)**: 커서 오프셋 `+-1` 범위의 캡처 노드를 수집하고, `strip_inclusive`로 상하위 노드 간의 엄격한 깊어짐(deepening chain)만 남김. 여러 줄에 걸친 심볼 텍스트는 첫 줄에서 잘라내어 breadcrumb 오버플로를 방지함.
- **메모리 수명 관리 (`EditorExtras`)**: `register_extras`에서 `map.retain(|_, e| Rc::strong_count(&e.highlighter) > 1)`를 수행하여 닫힌 탭의 에디터 슬롯을 안전하게 정리함. 메모리 누수 방지 설계 적합.
- **미리보기 코드 블록 하이라이터**: `PREVIEW_HIGHLIGHTER` 싱글톤 `RwLock<Option<Arc<PreviewHighlighter>>>`를 사용하며, 테마 변경 시 `set_theme`에서 `None`으로 drop되어 테마 전환 시 캐시가 자동 갱신됨.
- **인덱싱 안전성**: 문자열 슬라이스 시 `is_char_boundary` 검사 및 `.min(len)` 바운드 체크가 철저하여 멀티바이트(한글, 이모지) 입력 시 패닉 위험 없음.

### 3.2 `src/ui/breadcrumb.rs`
- `Crumb` 구조체 도입: 텍스트와 하이라이트 런(`Vec<(Range<usize>, HighlightStyle)>`)을 함께 보관.
- 마크다운 헤딩은 `title` 색상의 단일 런으로 처리하고, 코드 심볼은 문법 색상 런을 온전히 유지.
- `MAX_SEGMENTS = 12` 초과 시 중간 생략(`⋯`) 처리 로직이 런 범위를 훼손하지 않고 정확히 동작함.

### 3.3 `src/ui/pane_view.rs`
- 빵부스러기(Breadcrumb) 구성 시 활성 탭이 마크다운일 경우 `heading_trail` + `Crumb::colored`, 코드 파일일 경우 `syntax::symbols_at` + `Crumb::from`으로 올바르게 분기.
- 각 패널/탭의 커서 위치를 독립적으로 읽어 스플릿 뷰에서도 각 창에 맞는 심볼 경로가 정확하게 계산됨.

### 3.4 `src/ui/pane_group.rs`
- 에디터 생성 시 `EditorExtras`를 생성하여 `highlighter_factory`와 `register_extras`에 바인딩.
- `open`, `fill`, `clone_view`, `split` 시 `syntax::set_language`를 일관되게 호출.
- `refresh_languages`: 파일 이름 변경(rename) 이벤트 발생 시 확장자/첫 줄에 따라 언어 설정을 즉시 재동기화하여 문법 하이라이터 및 soft-wrap 설정을 갱신함.
- `sync_soft_wrap`: 프레임 렌더 직전 활성 에디터에 대해 `Window` 컨텍스트를 활용하여 지연 없이 soft-wrap을 적용함.

### 3.5 `src/ui/markdown_preview.rs`
- 코드 블록 배경색을 에디터 배경색(`theme.background`, One Dark `#282c33`)으로 일치시킴.
- 테두리: `border_variant`(`CodeBlockBorder`) 1px 적용.
- 간격 보정: `TextView`가 블록 뒤에 기본으로 더하는 `paragraph_gap`을 상쇄하기 위해 `.mt(16).mb(-16)` 처리하여 연속된 두 코드 블록 사이 간격을 Zed 실측값인 16px로 정확히 맞춤.

### 3.6 `src/ui/theme.rs`
- `style.syntax`를 순회하며 `color`, `font_style`, `font_weight`를 파싱하여 `SyntaxTheme`으로 변환.
- `CodeBlockBorder` 글로벌 상태 추가 및 테마 변경 시 `syntax::set_theme` 갱신 연동.
- `editor.foreground` 토큰이 없는 경우 One 테마 폴백을 적용하여 미캡처 텍스트가 UI용 텍스트 색상(`#dce0e5`)이 아닌 에디터용 글자색(`#acb2be`)으로 렌더되도록 보장함.

### 3.7 `src/ui/app_menu.rs` & `build.rs`
- `build.rs`: `cc` 라이브러리를 통해 4개 vendored C 파서를 정적 컴파일하며, `rerun-if-changed`가 정확히 설정되어 불필요한 재컴파일을 방지함.
- `app_menu.rs`: 추가된 27개 라이선스(tree-sitter 및 확장) 텍스트를 정적으로 번들링하여 도움말 라이선스 창에서 완결적으로 제공함.
