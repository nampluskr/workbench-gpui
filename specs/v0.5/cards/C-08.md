Zed(`C:\Users\nampl\AppData\Local\Programs\Zed\bin\zed`)를 띄워 확인한다. Zed 설정 파일은 고치지 않는다. 우리 앱은 띄우지 않는다.

- Zed 창을 클라이언트 1440×852로(`tools/measure/window-rect.ps1 -Action Resize` 재사용), 배율 100%(바꾸지 않음), Zed 기본 테마.

## 확인할 것
1. **I-9 스크롤바**: 편집 영역의 세로·가로 스크롤바가 (a) 마우스가 편집 영역 밖일 때, (b) 위에 가만히 있을 때, (c) 휠 스크롤 중일 때, (d) 스크롤을 멈춘 뒤 시간이 지나면 보이는지. (d)는 사라지기까지 시간을 캡처 여러 장(타임스탬프)으로 잰다. 참고: `docs/refs/01-zed/02-INTERACTION.md` E-033(`scrollbar.show` "auto": OS 자동 숨김이면 스크롤할 때 보이고 1초 뒤 숨김, 아니면 항상 보임, Windows 판정 미확인). Windows 설정 "스크롤 막대 항상 표시"(접근성) 값도 레지스트리에서 읽어 적는다(`HKCU\Control Panel\Accessibility` `DynamicScrollbars`). 설정은 바꾸지 않는다.
2. **I-14 한글 글꼴**: Zed 편집 영역의 한글이 어떤 글꼴로 그려지는지 도구로 판정한다(눈대중 금지). 예: Zed 캡처의 한글 영역과, 같은 크기로 Malgun Gothic·Gulim·GulimChe 등으로 그린 비교 이미지를 픽셀로 대조, 또는 Zed 프로세스가 연 글꼴 파일 확인 등 방법은 정해 적는다. 참고: `docs/refs/01-zed/03-THEME-ICONS.md` T-16(편집기: Lilex → Cascadia Mono → Consolas → Malgun Gothic, 판단).
3. 마우스·키보드 조작은 1의 상태를 만드는 데 필요한 만큼만. 끝나면 Zed를 닫는다(잔여 프로세스 0건 확인).
