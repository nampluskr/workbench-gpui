# K-05 — 편집 영역 스크롤바: 세로는 늘 보임, 가로는 넘칠 때만 (I-9)

## 요구 (core-leader DECISION 2026-11-07, 두 갈래가 확인한 Zed 동작)
- 스크롤할 내용이 있으면 **세로 스크롤바가 마우스 위치와 상관없이 늘 보인다**(숨김·페이드아웃 없음).
- **가로 스크롤바는 내용이 가로로 넘칠 때만** 보인다(자동 줄바꿈 문서에서는 보통 안 보인다).
- Zed 실측(C-09, `specs/v0.5/verify/reviews/zed-ORDER-03.md`): 세로 스크롤바 폭 15px(테두리 1px `#2e333c` + 엄지 14px `#585c63`, One Dark). 스크롤바 폭은 이미 스펙이 있다: `src/ui/metrics.rs` `scrollbar["width.editor"]`(L-308) 15. 색은 지금 테마 값 그대로 두고(테마 전환은 Phase 7), 폭·표시 조건만 맞춘다.
- 지금 gpui는 편집 영역에 마우스를 올려도 스크롤바가 보이지 않는다(core 확인). 원인을 코드로 찾는다(gpui-component `Editor`/`Input`의 스크롤바 표시 모드 설정, 예: `ScrollbarShow`/`scrollbar_visible` 같은 공개 옵션을 먼저 찾는다).

## 제약
- I-9 밖은 바꾸지 않는다. 다른 영역(파일 트리 등)의 스크롤바 동작은 그대로 둔다. 의존성·Cargo 변경 금지. 앱 실행 금지. 커밋 금지.
