## 런타임 오류 수정

### 1. 오류 원인
`Get-LatestSnapshot`이 반환하는 `$boxes`는 PowerShell `[ordered]@{}`(`System.Collections.Specialized.OrderedDictionary`) 객체다. 일반 `Hashtable`과 달리 `OrderedDictionary`는 `.ContainsKey()` 메서드를 제공하지 않고 `IDictionary.Contains()`만 구현되어 있어, `Assert-LayoutCondition` 및 조건문에서 `$s.boxes.ContainsKey(...)` 호출 시 `[System.Collections.Specialized.OrderedDictionary]에 'ContainsKey' 메서드가 없음` 런타임 오류가 발생했다.

### 2. 수정 내역 (`tools/measure/order03-v3.ps1`)
1. **`Set-StrictMode -Version Latest` 추가**:
   - 스크립트 실행 최상단(`param` 블록 직후)에 `Set-StrictMode -Version Latest` 배치.
2. **`OrderedDictionary` 메서드 호환성 수정**:
   - `Get-LatestSnapshot` 내 `$boxes`에 `ContainsKey` 스크립트 메서드를 `Add-Member`로 바인딩하여 양방향 호환성 확보.
   - 스크립트 전체 19개 지점의 `.ContainsKey(` 호출부를 `.Contains(`로 일괄 교체.
3. **Strict Mode 런타임 전용 잠재 오류 정적 제거**:
   - `$global:LASTEXITCODE = 0` 초기화: 외부 프로세스 실행 전 `$LASTEXITCODE` 참조 시 미정의 변수 예외 방지.
   - `Get-LatestSnapshot` 내 `$seq = -1` 선언: 정규식 매칭 전 변수 참조 안전성 확보.
   - `$session.PSObject.Properties['fixture']` 안전 점검: PSCustomObject의 미정의 속성 참조 예외 방지.
   - `$zedPidsBefore` 및 `$currentPids`를 `[uint32[]]`로 명시적 형변환: `Order03Native::GetProcessTopLevelWindows(uint[] pids)` P/Invoke 시그니처 엄격 일치.
   - S-9 박스 바운드 추출 시 `$snap -and $snap.boxes.Contains('active-item')` 안전 가드 추가.
4. **함수 정의 로드 가드**:
   - 메인 실행부(Section 6) 및 첫 시작 로그를 `if ($MyInvocation.InvocationName -ne '.')` 블록으로 감싸, 스크립트 dot-sourcing 시 앱이나 Zed를 띄우지 않고 함수 정의 및 타입만 안전하게 메모리에 로드되도록 변경.
