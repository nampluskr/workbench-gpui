# C-13 — order03-v3.ps1 앱 흐름 고치기 (1차 실행 실패)

leader가 화면 차례 안에서 C-12 이전 판(C-11 판)을 `-Only App`으로 실행했다(01:52). 앱 데이터는 정상 복원됐지만 **캡처가 모두 무효**다: 앱이 "Open Project" 첫 화면(트리 없음, 탭 `untitled (placeholder)`)에 머물러 파일이 열리지 않았다. 결과: `specs/v0.5/verify/reviews/measure-ORDER-03/`(`log.txt`, `layout.json`, `app-stdout.txt`, `pick.txt`, 캡처 13장). 이 폴더를 읽어 원인을 찾는다.

log에서 보인 문제:
1. `window-rect.ps1 -TargetHwnd` 리사이즈 실패(`-ProcessName` 없이 'workbench-gpui' 창을 못 찾음 → C-12와 같은 문제, 앱 쪽도 고친다).
2. `Foreground window != target` 경고.
3. `tree-row-01`을 찾지 못해 "fallback clicking tree item area" — 프로젝트가 열리지 않았다. `--dev-pick-folder`는 폴더 선택 대화상자 대신 fixture 폴더를 주는 것으로 보이니, 먼저 "Open Project"(또는 해당 키)를 눌러야 할 수 있다. `tools/verify-v02-*.ps1`·`tools/measure/session.ps1`·`src/dev.rs`에서 실제 흐름을 확인한다.

## 고칠 것
- 앱 흐름: 프로젝트 열기 → fixture 파일 열기 → 편집 상태 → 각 상태. 각 단계 뒤 **레이아웃 덤프로 기대 상태를 확인**하고(예: 트리 행, 에디터 박스, 분할 pane 2개, 미리보기 탭), 아니면 그 자리에서 캡처 1장·로그 남기고 **중단**한다(뒤 단계를 헛돌지 않게). 무효 캡처를 만들지 않는다.
- 창 크기·포그라운드: 리사이즈 성공을 `GetClientRect`로 확인(1440×852), 실패하면 중단.

- AST 파싱 검사만. 실행하지 않는다. 이미 열린 창·프로세스는 건드리지 않는다.
