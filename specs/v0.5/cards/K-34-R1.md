# K-34-R1 — 경로 줄 색: `›` placeholder, 마크다운 제목 문법 색
K-34 보고의 "toml/토큰 필요" 두 색을 이 앱 테마 데이터로 맞춘다. 테마는 Zed 테마 JSON(`resources/zed-themes/`)을 `theme.rs`의 `resolved_color(style, base, key)`로 읽으므로 새 값 추정 없이 된다.
1. `›`: Zed 테마 키 `text.placeholder`. `theme.rs`에 기존 `close_hover_bg` 같은 공개 함수 또는 전역(gutter처럼 `apply`에서 `set_global`)으로 노출 — 렌더에서 JSON을 매번 찾지 않게 `apply` 때 한 번 계산. One 대체(base) 규칙은 기존과 같게.
2. 제목 조각: Zed 테마 `style.syntax.title.color`(Zed 마크다운 `outline.scm`의 제목이 `title` 캡처 — C-36). 없으면 `muted_foreground`(지금 값)로. 경로 조각은 `Color::Muted` 그대로.
3. 테마를 바꾸면(테마 선택기) 두 색도 따라 바뀌어야 한다(`apply`에서 갱신).
4. 테스트: One Dark 항목에서 두 색이 JSON 값과 같은지(테마 JSON이 없으면 건너뛰는 기존 테스트 방식을 따른다).
확인: `cargo build`, `tools/apply-manifest.ps1`, 관련 테스트, `cargo clippy --all-targets -- -D warnings`. 앱 실행·커밋 없음. 보고 `specs/v0.5/cards/K-34-R1.report.md`. 답은 경로만.
