## 3. 데이터 손실 방지 (저장 충돌 거부) 검증

1. **Keymap Editor (`save_binding`)**:
   - 모달 열람 시 `read_snapshot(&path)`으로 디스크 원문 문자열을 `expected`에 보관.
   - 저장 시점에 디스크 내용을 다시 읽어 `current.as_deref() != expected`이면 즉시 `Err("Keymap changed on disk. Reopen the binding before saving.")`를 반환.
   - 디스크 파일은 일체 쓰기/수정되지 않으며(Zero Data Loss), 화면 모달에 오류 메시지 노출 및 알림 전송.
   - 테스트 `k17_save_refuses_changed_created_or_deleted_files`에서 외부 변경/생성/삭제 시 디스크 바이트 보존 및 거부 동작 확인.
2. **Settings 창 (`save`)**:
   - 창 생성 시 `read_snapshot`으로 `expected` 보관.
   - 설정값 변경 시 `&current != expected`이면 즉시 `Err("Settings changed on disk. Reopen Settings before saving.")` 반환 및 알림 전송. 디스크 파일 보존.
   - 정상 저장 성공 시 `*expected = Some(text)`로 메모리 스냅샷을 전진시켜 동일 창에서 연속 수정 가능.
   - 테스트 `k18_settings_conflicts_preserve_disk_and_own_saves_advance_snapshot` 통과.
