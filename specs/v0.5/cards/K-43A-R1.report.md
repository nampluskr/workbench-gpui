## 2. 구현

- `build.rs`: `cc::Build`로 `parser.c`·`scanner.c`를 `vendor/tree-sitter-html/src`를 include 경로로 컴파일(`-Wno-*`는 원 저장소 `bindings/rust/build.rs`와 같은 플래그). `cargo:rerun-if-changed`는 `vendor/tree-sitter-html/src`와 `build.rs`만 — 앱 소스만 바꾼 증분 빌드는 C를 다시 컴파일하지 않는다(`syntax.rs`만 touch한 빌드 11.0초).
- `cc = "=1.10.0"`: 이 레포 lock의 유일한 cc 버전(`name = "cc"` 1개). 새 package 없음.
- `tree-sitter-language = "=0.1.8"` **직접 의존성 추가**: `tree_sitter`가 `LanguageFn`을 재노출하지 않아(`use`뿐, `pub use` 아님) `LanguageFn::from_raw`를 쓰려면 필요하다. 이미 lock에 있는 `[patch.crates-io]` git 판(core와 같은 rev)이 쓰이므로 새 package나 버전 변화 없이 workbench-gpui의 의존 목록에 줄만 늘었다(lock에서 확인). 카드가 "LanguageFn으로 노출"을 지시해 필요한 최소 변경이라 적용했다 — 승인 범위를 넘는다고 보면 알려 달라.
- `syntax.rs`: `unsafe extern "C" { fn tree_sitter_html() -> *const (); }` + `html_language()`(`LanguageFn::from_raw(...).into()`, SAFETY 주석) → `grammar("html")`. 쿼리는 기존 `load_queries`의 기본 `H I O`로 컴파일(html은 세 파일 모두 있음).
- 파서 ABI: `LANGUAGE_VERSION 14`(core 0.28이 받는 범위), K-43A에서 확인.
