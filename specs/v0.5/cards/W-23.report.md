### R-2 Keymap Editor

| 대상 | gpui | tauri |
|---|---|---|
| 기존 탭 찾기 | 모든 폴더 workspace에서 찾아 활성화 | 같은 폴더에 있을 때만 앞으로 |

| Arguments | 빈 칸 | `<no arguments>`, `<null>`, 배열 인자 JSON |
| Keystrokes | gpui 표기 `ctrl-k ctrl-s` | 표시 형식 `Ctrl-K Ctrl-S` |
| Context 빈 값 | 빈 칸 | `<global>` |
| 필터 | Action 원래 이름 부분 일치 | 읽기 쉬운 이름·원래 이름, 공백으로 나눈 검색어 모두 |

| Action 입력 | 글자 입력, 저장 때 검사 | 등록 액션 자동완성 |
| 저장 충돌 검사 | 저장 때 파일을 다시 읽어 덧붙임 | 모달을 열 때 원문과 다르면 거부 |
