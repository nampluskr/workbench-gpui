# C-25 — ORDER-06-R1 V3 스크립트 (끝난 부분 먼저)

`tools/measure/order06-r1-v3.ps1`(order06-v3.ps1 재사용; session.ps1 출력 파이프 문제 고친 방식 유지, `Ensure-ClientSize`, 단계 독립, 실패 기록 후 계속, 띄운 PID와 **내가 연 창만** 닫기, Zed 안 띄움). 앱 단계:
1. Settings 창: `Ctrl-,` → 새 창(HWND 차이로 감지) 캡처, 창 크기(GetClientRect)와 SPEC R-2 Zed 실측 치수 대조용 값 로그, 다시 `Ctrl-,` → 새 창이 생기지 않고 기존 창이 앞으로 오는지, 검색칸에 "font" 입력 → 결과 캡처, Buffer Font Size 값을 바꿔 저장·즉시 적용(편집기 글자 크기 변화 캡처) → `%APPDATA%\workbench-gpui\settings.json` 내용 로그 → **앱 재실행 후 값 유지** 확인 → 원래 값으로 되돌림. 앱 데이터는 session.ps1이 백업·복원하지만, settings.json이 session 백업 대상인지 확인하고 아니면 스크립트가 직접 백업·복원한다(데이터 손실 금지).
2. `Edit in settings.json` → 편집기 탭 열림 캡처.
3. Panel Layout: dock 닫기 → v 메뉴 Panel Layout 캡처(Custom 체크·비활성) → Classic 클릭 → dock 열림·기본 폭 캡처.
4. View → Editor Layout 하위 메뉴 캡처(Split 네 항목·단축키).
5. 탭 순환: 트리에서 두 파일을 **더블클릭**으로(미리보기 탭이 아닌 고정 탭으로) 열어 탭 2개 확인 → Ctrl-PageDown·Ctrl-PageUp 캡처(활성 탭 이동·순환).
문법 검사·`-DryRunStdout`(최근 app-stdout). Keymap·Extensions 단계는 구현 뒤 더한다.
보고: `specs/v0.5/cards/C-25.report.md`, 답은 '[DONE] 화면 요청 가능' 또는 남은 것.
