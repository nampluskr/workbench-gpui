### 같은 것

- 메뉴 순서: workbench-<갈래>·File·Edit·View·Go·Window·Help. Selection·Run 없음.
- File: Open Folder... `Ctrl-K Ctrl-O`, (구분선), Save `Ctrl-S`, (구분선), Close Editor, Close Window `Ctrl-Shift-W`.
- Edit Undo `Ctrl-Z`. View: Toggle Left Dock `Ctrl-B`, Toggle Folder Sidebar `Ctrl-Alt-J`, Focus Folder Sidebar `Ctrl-Alt-;`, 분할 네 항목의 단축키(`Ctrl-K Up/Down/Left`, Split Right `Ctrl-\`·`Ctrl-K Right`), Maximize Pane `Shift-Escape`, (구분선), Project Panel `Ctrl-Shift-E`, Open Markdown Preview `Ctrl-Shift-V`, …to the Side `Ctrl-K V`.
- Go: Previous Tab `Ctrl-PageUp`, Next Tab `Ctrl-PageDown`. Window: Minimize, Zoom(단축키 없음).
- Help: View Dependency Licenses, (구분선), File Bug Report..., Request Feature..., (구분선), workbench-<갈래> Repository. URL은 각 갈래 저장소(의도된 차이).
- "v" 메뉴: Settings `Ctrl-,`, Keymap `Ctrl-K Ctrl-S`, Themes… `Ctrl-K Ctrl-T`, Icon Themes…(없음), Extensions `Ctrl-Shift-X`, (구분선), Panel Layout ▸ Classic·Agentic. 다섯 항목과 Classic·Agentic 비활성, Custom 없음.

### 참고 (메뉴·항목·순서·단축키 밖, 고칠지는 leader 판단)

| 대상 | gpui | tauri |
