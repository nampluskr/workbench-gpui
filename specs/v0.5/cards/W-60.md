# W-60 — docs/BUILD.md(배포본 빌드 과정), README 링크, .gitignore 산출물 막기, PROGRESS 기록
사실은 아래 근거 파일에서만 가져온다. 근거가 없으면 지어내지 말고 "미정"/"확인 안 함"으로 적고 보고에 남긴다. src는 읽기만, 빌드·앱 실행·커밋하지 않는다.

근거: `specs/v0.5/reports/RELEASE.md`, `specs/v0.5/cards/K-51.report.md`, `specs/v0.5/verify/reviews/C-46.md`, `tools/package-release.ps1`, `tools/apply-manifest.ps1`, `tools/fetch-zed-icons.ps1`·`fetch-zed-themes.ps1`·`fetch-zed-languages.ps1`, `build.rs`, `.cargo/config.toml`, `Cargo.toml`, `specs/v0.5/HERDR-SETUP.md` 2.2(빌드 환경), `resources/zed-icons/LICENSES`·`LICENSE-*`, `resources/licenses/`, `src/ui/app_menu.rs` 260~305줄(라이선스 목록), README.md.

1. **`docs/BUILD.md`(새 파일, 한국어)** — 절:
   - 필요한 도구와 버전: Rust 1.99.1(`rustc 1.99.1 (58cf8f9c3 2026-10-13)`, `cargo 1.99.1`), Visual Studio Build Tools 2022(MSVC, C 소스 크레이트·링크), Windows SDK 10.0.26100.0(`mt.exe` — apply-manifest), PowerShell 7, git(fetch 스크립트가 고정 커밋을 받는다), 네트워크(처음 fetch·crates). **Node·tree-sitter CLI는 필요 없다**(leader 확인: tools·build에서 쓰지 않음, 문법은 크레이트·vendored C 소스로 빌드). `build.rs`가 하는 일을 읽고 한 줄로.
   - 복사본 채우기(fetch-*): 세 스크립트 각각이 채우는 폴더(`zed-icons`, `zed-themes`·`zed-icon-themes`, `zed-languages`), 받는 곳·고정 커밋, 순서(서로 독립이면 그렇게), 이 폴더들이 `.gitignore` 대상이라 새로 clone하면 꼭 실행해야 함.
   - 빌드 명령 전체: 개발 빌드(`cargo build` → `apply-manifest.ps1`), 배포본(`pwsh -NoProfile -File tools/package-release.ps1`, `-NoBuild`), 스크립트가 하는 단계, `CARGO_TARGET_DIR`. 정적 CRT(`.cargo/config.toml`)와 rustflags가 바뀌면 전부 다시 빌드됨. 설치 파일(msi 등)은 없다.
   - 결과 파일 경로와 크기(2026-11-08 값): exe 41.61 MB(43,631,616 B), 배포 폴더 `target\dist\workbench-gpui\` 47.22 MB·5,751 파일, zip `target\dist\workbench-gpui.zip` 16.36 MB(17,154,349 B). 폴더 구성.
   - 걸린 시간: release 처음부터 5분 2초(패키지 스크립트 전체 5분 23초), debug 3분 36초, 의존성 캐시가 있을 때 release 약 79초(RELEASE 이전 측정, 크레이트만 재컴파일). 측정 PC: HERDR-SETUP 2.2의 데스크톱.
   - 다른 PC로 옮기는 법: zip을 풀고 `workbench-gpui\workbench-gpui.exe` 실행, `resources\`는 exe와 같은 폴더, VC++ 재배포 패키지 필요 없음, 확인 방법(stderr `resources: <경로>` 줄), 사용자 설정·상태 파일 위치가 근거에 있으면 적고 없으면 생략.
   - 알려진 제약: RELEASE.md "남은 제약" 1~6(실제 다른 PC 미확인, 콘솔 창, OS 조건 icuuc·LongPathsEnabled·x64, 빈 resources 판단, 서명 없음·SmartScreen, 재빌드 시간).
   - 라이선스 주의: 배포물에 함께 들어가는 복사본 — Zed 쿼리(`zed-languages`, Zed 저장소 GPL-3.0 쪽 파일, TOML·git-firefly 확장 쿼리는 Apache-2.0), Zed 아이콘·테마·아이콘 테마 복사본(근거 파일의 라이선스 그대로). **이 복사본들은 개인 용도로 두는 것이며 배포물에 포함된다**는 점, 재배포 전 각 라이선스를 확인해야 한다는 점. 앱 코드는 Zed 코드를 복사하지 않는다(AGENTS 레포 규칙). 라이선스 이름은 근거 파일에 적힌 것만.
   - GitHub에 올리지 않는 것: 빌드 산출물(exe·zip·설치 파일·pdb·`target/`·`dist/`·`bundle/`)은 커밋하지 않는다. 확인 결과(2026-11-08): `git ls-files`에 산출물 없음(leader 확인: `\.(exe|zip|msi|pdb|dll|7z)$`, `target/`·`dist/`·`bundle/` 경로 0건). `.gitignore`는 원래 `target/`만 막았고 이 카드에서 2를 더함.
2. **`.gitignore`**: 맨 위 `target/` 다음에 `dist/`, `bundle/`, `*.exe`, `*.zip`, `*.msi`, `*.pdb`를 더한다(한 줄 주석: build outputs are never committed). 다른 줄은 고치지 않는다.
3. **README.md**: 적당한 곳(맨 아래 또는 상태 절 뒤)에 `docs/BUILD.md` 링크 한 줄만 더한다. 다른 문장은 고치지 않는다.
