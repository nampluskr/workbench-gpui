## 2. Zed 소스 확인 결과

### 2.1 코드 블록 구문 강조 여부 및 언어 확인 규칙 (Q1)

1. **구문 강조 여부**:
   - Zed 마크다운 미리보기는 코드 블록을 **언어별로 구문 강조(Syntax Highlighting)합니다**.
   - `crates/markdown_preview/src/markdown_preview_view.rs:392~395`:
     미리보기 뷰 생성 시 `Markdown::new_with_options`에 `Some(language_registry)`를 전달하여 언어 레지스트리를 연동합니다.

2. **언어 식별 및 검색 규칙 (info string)**:
   - **파서 단계** (`crates/markdown/src/parser.rs:425~439`):
     - 코드 펜스의 info string 양쪽 공백을 제거(`info.trim()`)합니다.
     - 빈 문자열이면 untagged로 처리하여 `CodeBlockKind::Fenced`로 분류합니다.
     - 슬래시(`/`)가 포함되어 있으면 파일 경로로 취급하여 `CodeBlockKind::FencedSrc(PathWithRange)`로 분류하고 `language_paths`에 등록합니다.
     - 그 외 일반 문자열이면 `CodeBlockKind::FencedLang(language)`로 분류하고 `language_names`에 등록합니다.
   - **언어 조회 단계** (`crates/markdown/src/markdown.rs:1334~1345`):
     - `registry.language_for_name_or_extension(&name)`으로 언어를 조회합니다.
     - 조회가 실패하고 공백이 포함된 경우(`name.split_once(char::is_whitespace)`), 공백 앞의 첫 단어(`first_word`)로 다시 `registry.language_for_name_or_extension(first_word)`를 조회합니다 (예: ````rust no_run```` -> `rust`).
   - **편집기 주입(Injection) 규칙과의 일치 여부**:
     - 편집기 Tree-sitter 주입 및 파일 타입 판별과 **동일한 규칙**입니다. 언어 이름(`name`) 또는 파일 확장자(`path_suffixes`)를 대소문자 구분 없이 매칭하며, 첫 단어 분리 fallback을 지원합니다.

3. **강조 색 출처**:
   - `crates/markdown_preview/src/markdown_preview_view.rs:1108~1114`:
     - `MarkdownStyle::themed_with_overrides(MarkdownFont::Preview, theme.colors(), theme.syntax(), window, cx)`
   - 테마의 `theme.syntax()`(`Arc<SyntaxTheme>`)를 직접 넘기며, 이는 **편집기 코드 강조에 쓰이는 테마 syntax 토큰과 완전히 동일**합니다.
   - `crates/markdown/src/markdown.rs:4224~4235`:
     Tree-sitter로 파싱된 토큰 ID를 `self.syntax_theme.get(*highlight_id)`로 조회하여 텍스트 런에 스타일을 입힙니다.

### 2.2 코드 블록 스타일 및 언어 부재/알 수 없는 언어 처리 (Q2)

1. **코드 블록 스타일 수치 및 출처**:

     - 에디터 배경색과 동일한 색상을 사용합니다.
   - **내부 여백 (Padding)**:
     - `12px` (상·하·좌·우 전체 12px, `crates/markdown/src/markdown.rs:372~377`)

     - `border: false` (테두리 없음, `crates/markdown_preview/src/markdown_preview_view.rs:1124`)
   - **글꼴 (Font)**:

   - **글꼴 크기 (Font Size)**:

2. **언어가 없거나(Untagged) 모르는 언어일 때의 동작**:
   - `crates/markdown/src/markdown.rs:1664~1673`:
     - untagged(`CodeBlockKind::Fenced`)는 fallback 언어가 없으면 `None` 반환.
     - 알 수 없는 언어는 `languages_by_name`에 없어 `None` 반환.
     - 들여쓰기 코드 블록(`CodeBlockKind::Indented`)은 항상 `None` 반환.
   - `crates/markdown/src/markdown.rs:4246`:
     - 언어가 없거나 하이라이트 런이 없으면 `else { self.pending_line.runs.push(text_style.to_run(text.len())); }`로 분기합니다.
   - **결과 동작**:
     - 구문 강조 없이 기본 텍스트 색상(`colors.text`)의 평문으로 렌더링됩니다.
     - 컨테이너 스타일(에디터 배경색, padding 12px, margin-y 16px, radius 6px, 에디터 고정폭 글꼴)은 **강조 언어가 있을 때와 완전히 동일하게 유지**됩니다.

## 3. 요약 및 제언

1. **Zed 동작 확인 결론**:
   - Zed는 마크다운 미리보기 코드 블록에 대해 편집기와 동일한 Tree-sitter 구문 강조(`theme.syntax()`)를 적용합니다.
   - 언어 검색은 코드 펜스 info string의 첫 단어 및 확장자 기반 대소문자 무시 조회입니다.
   - 언어가 없거나 불일치할 경우 평문 색상으로만 폴백되고 블록 상자 스타일(배경/여백/반경)은 유지됩니다.

2. **우리 구현 반영 방향**:
   - `gpui-base`의 `TextView`에 이미 `code_block_highlighter(|code_block: &CodeBlock| -> Vec<(Range<usize>, HighlightStyle)>)` 메서드가 마련되어 있습니다.
   - Phase 11에서 Tree-sitter 문법 및 테마 syntax 하이라이트 쿼리가 구축되면, `src/ui/markdown_preview.rs`에서 `code_block.lang()`을 조회하여 하이라이트 스타일 범위를 반환하도록 연결하면 Zed와 동일하게 동작할 수 있습니다.
   - 코드 블록 배경색은 현재 `theme.muted`이나 Zed 소스는 `editor_background`이므로 필요 시 조정 대상입니다.
