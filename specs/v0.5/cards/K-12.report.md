## 이름 간격 계산

IBM Plex Sans Regular(번들 TTF), 이름 글자 크기 12px 기준. fontTools로 glyph outline 경계와 hmtx advance를 읽었다. 간격 = 앞 이름 마지막 글자의 오른쪽 측면 여백 + 우측 padding + NAME_GAP + 좌측 padding + 뒤 이름 첫 글자의 왼쪽 측면 여백. gap 4px는 유지하고 좌우 padding만 6 → 4px로 변경했다.

| 이름 경계 | 양쪽 글자의 측면 여백 합(px) | 변경 전 예상(px) | 변경 후 예상(px) |
|---|---:|---:|---:|
| workbench-gpui / File | 2.028 | 18.028 | 14.028 |
| File / Edit | 1.680 | 17.680 | 13.680 |
| Edit / View | 0.768 | 16.768 | 12.768 |
| View / Go | 1.068 | 17.068 | 13.068 |
| Go / Window | 0.804 | 16.804 | 12.804 |
| Window / Help | 1.488 | 17.488 | 13.488 |

변경 후 `2×4 + 4 + 측면 여백` = 12.768~14.028px로 목표 13~14px에서 최대 0.232px 벗어난다(허용 1px 이내). 이는 폰트 outline 계산이며 실제 래스터화·힌팅·픽셀 반올림은 V3에서 판정한다. 이름 길이나 다른 글꼴에서는 다시 대조해야 한다.
