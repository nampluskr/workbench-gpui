## 1. 스크립트 설계 및 안전 원칙 준수

`tools/measure/order08-zed.ps1`은 ORDER-08 2장 및 C-33 지침에 따라 Zed 단독 검증 전용으로 완성되었습니다.

1. **비율 기반 좌표 산정 (레이아웃 덤프 부재 대응)**:
   - Zed는 앱과 달리 레이아웃 덤프가 없으므로 클라이언트 크기(`$clientW`, `$clientH`) 기준 비율로 좌표를 산정합니다:
     * 상태 표시줄 높이: `$clientH * (30.0 / 852.0)` (표준 1440×852에서 30px)
     * 상태 표시줄 Top: `$clientH - $sbHeight` (822px)
     * 좌측 버튼 중심: 버튼 1(도크 토글) `$clientW * (15.0 / 1440.0)`(15px), 버튼 2(검색) `$clientW * (39.0 / 1440.0)`(39px), 버튼 3(진단) `$clientW * (63.0 / 1440.0)`(63px), Y 중심 `$sbTop + ($sbHeight / 2)`
     * 우측 정보군 너비: `$clientW * (350.0 / 1440.0)`(350px)
2. **캡처 해시 전후 비교를 통한 상태 변화 능동 검증**:
   - `Assert-CaptureChanged` 헬퍼를 도입하여 각 상호작용 단계 전후의 전체 창 캡처 SHA256 해시를 비교합니다:
     * `doc.md` 열림 확인 (열기 전 vs 후 해시 불일치)
     * 커서 이동 확인 (이동 전 vs 후 해시 불일치)
     * 선택 영역 생성 확인 (선택 전 vs 후 해시 불일치)
     * 언어별 파일(`.rs`, `.json`, `.ts`, `.txt`) 열림 확인
     * 1초 hover 툴팁 표출 확인 (hover 전 vs 툴팁 표출 후 해시 불일치)
     * 좌측 도크 열림/닫힘 상태 전이 확인 (도크 open vs closed 해시 불일치)
     * Project Search 탭 전개 확인 (버튼 클릭 전 vs 빈 검색 탭 열림 후 해시 불일치)
     * 검색 쿼리 실행 및 결과 표출 확인 (빈 검색창 vs 쿼리 결과 렌더링 후 해시 불일치)
     * Diagnostics 탭 전개 확인 (버튼 클릭 전 vs 진단 탭 열림 후 해시 불일치)
3. **Zed 단독 구동 및 앱 불간섭**:
   - 우리 앱은 전혀 실행하지 않으며, `session.ps1` 및 앱 데이터 백업/복원 과정도 불필요하여 제외했습니다.
   - Zed는 `Start-Process -FilePath $ZedExe -ArgumentList @('-n', "`"$fixtureDir`"")`로 새 창으로만 띄우며 `-a` 인자는 엄격히 금지했습니다.
4. **독립 창 추적 및 안전 종료**:
   - 실행 전 Zed 최상위 창 목록(`$beforeHwnds`)을 수집하고, 실행 후 새로 생성된 HWND만 식별하여 대상으로 지정합니다.
   - 측정이 끝나면 대상 창에만 `WM_CLOSE`(`PostMessage`)를 보내어 안전하게 닫습니다. 파일 수정이 없으므로 저장 대화상자는 뜨지 않으나, 혹시 대화상자가 뜨더라도 강제 종료하지 않고 로그를 남기도록 방어했습니다.
5. **사용자 설정 불변성 보장 (100%)**:
   - `%APPDATA%\Zed\settings.json`, `keymap.json`의 SHA256 해시 및 파일 크기를 측정 전/후로 비교하여 단 1바이트의 변경도 없음을 검증합니다.
   - Zed Settings (`Ctrl-,`)는 일체 열지 않습니다.
6. **Fixture 자동 준비**:
   - `-Out` 디렉터리 하위에 `order08-fixture/`를 자동 생성합니다:
     * `doc.md` (마크다운)
     * `src/main.rs` (Rust)
     * `data.json` (JSON)
     * `app.ts` (TypeScript)
     * `notes.txt` (일반 텍스트)
     * 검색 테스트를 위해 공통 검색어 `TARGET_SEARCH_KEYWORD`가 각 파일에 여러 번 포함되어 있습니다.
7. **독립 단계 및 필터링 지원**:
   - 모든 단계는 `-Steps` 및 `-Skip` 인자로 개별 실행이 가능하며, 예외 발생 시에도 `finally` 블록에서 Zed 창 종료 및 설정 해시 검증이 100% 보장됩니다.
