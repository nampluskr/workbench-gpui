## 1. 사용자 설정 파일 (core-leader 결정, 두 갈래 같게)
- `%APPDATA%\workbench-gpui\settings.json`, Zed 형식(JSONC 허용, 키 이름 Zed와 같음). 키: `theme`, `icon_theme`, `ui_font_size`(기본 16), `buffer_font_size`(기본 15). 파일이 없거나 값이 없으면 지금 상수가 기본값. 이미 있는 jsonc 파서(`jsonc-parser`)와 기존 state 저장 방식(원자적 교체, `src/state/`)을 재사용.
- 값을 바꾸면 바로 저장·바로 적용(테마는 지금 있는 테마만, 아이콘 테마는 `Zed (Default)` 하나 — Phase 7에서 늘어남). `ui_font_size`는 rem 기준값(K-03-R1 해석), `buffer_font_size`는 에디터 본문 크기.
- 저장 시험은 테스트 데이터 폴더에서(V1 테스트, 실제 사용자 폴더 건드리지 않게 경로 주입).

## 2. Settings 창 (`Ctrl-,`, "v" 메뉴 Settings)
- Zed처럼 **별도 OS 창**. 이미 열려 있으면 앞으로.
- 왼쪽: 맨 위 검색칸 "Search settings…", 그 아래 범주 목록 — 범주는 `Appearance` 하나.
- 오른쪽 위: 범위 `User`만, `Edit in settings.json` 버튼(설정 파일을 편집기 탭으로 연다; 파일 없으면 빈 `{}`로 만들어 연다).
- 본문 행 4개: Theme(드롭다운), Icon Theme(드롭다운), UI Font Size(숫자), Buffer Font Size(숫자). 행마다 이름·설명 — **Zed Settings UI 문구 그대로**(같은 커밋 `4304dec732…`의 settings UI 소스에서 이름·설명 문자열을 찾아 쓴다, 레포 밖 `%TEMP%\zed-src-4304dec7`에 필요한 crate만 sparse로 더해 읽기만, 코드 복사 금지).
- 검색은 이름·설명에서 찾는다.
- 창 치수·간격: tauri가 Zed 캡처에서 잰 값을 tauri SPEC에서 읽어 쓴다(`D:\projects\workbench-tauri\specs\v0.5\SPEC.md`, 읽기만; 아직 없으면 보고에 "tauri 값 대기"로 적고 임시값을 두지 말고 해당 상수 자리만 표시). 컨트롤 모양은 gpui-kit 컴포넌트를 먼저 쓴다.
