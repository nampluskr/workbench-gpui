## 2. V3 스크립트 작성 (실행하지 않는다)
checker는 격리 데스크톱이라 입력이 안 된다. 그래서 **leader가 화면 차례 안에서 실행할** PowerShell 스크립트를 `tools/measure/order03-v3.ps1`로 쓴다(checker 소유 폴더). 너는 실행하지 말고, leader가 실행한 뒤 결과 파일로 판정한다(다음 카드).

스크립트 요구:
- 출력 폴더 `-Out`(기본 `specs\v0.5\verify\reviews\measure-ORDER-03`). 단계마다 `log.txt`에 시각·동작·좌표를 남긴다.
- 우리 앱: `tools/measure/session.ps1 -Action Start ... -Exe D:\projects\workbench-gpui\target\debug\workbench-gpui.exe`로 앱 데이터 백업·초기화 뒤 실행, 끝에 `-Action Stop`으로 복원. 앱 PID는 `session.json`에서 읽고 **그 PID만** 닫는다(이미 열린 다른 창·프로세스는 건드리지 않는다, core-leader DECISION). 레이아웃 덤프(`--dev-layout-json`)가 있으면 박스 좌표를 써서 클릭한다(`tools/measure/input.ps1`의 `-Box`, `Hover`, `Wheel`, `Key` 재사용).
- 열 파일: 한글·영문·긴 줄·코드 블록·제목이 있는 마크다운 하나(예: 이 레포 `specs/v0.5/SPEC.md`, 또는 `-Out` 아래에 만든 fixture). 편집 상태로 연다.
- 캡처는 `tools/capture.ps1 -Method Screen`(PrintWindow는 오버레이를 빠뜨린다, C-09).
- 화면 상태(C-10 4장 제안 + I-8·I-9): S-1 편집 영역 본문(I-14 Lilex 15/줄 높이), S-2 커서 줄 강조(I-13: 커서를 다른 줄·soft wrap된 긴 줄로 옮겨 각각 캡처), S-3 단일 pane과 좌우 분할(I-7: 경계 확대 캡처), S-4 한글 본문(I-14 한글 고딕), S-5 미리보기(I-14 본문 Plex Sans·제목 600·코드 Lilex), S-6 UI 셸(메뉴 열림, 툴팁 하나), S-7 마크다운 긴 줄 자동 줄바꿈·가로 스크롤바 없음(I-8), S-8 마우스를 편집 영역 밖에 둔 상태와 휠 뒤 4초 상태의 세로 스크롤바(I-9).
