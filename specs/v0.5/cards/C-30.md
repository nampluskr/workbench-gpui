# C-30 — 측정 세션 도구 단단히 (사용자 앱 데이터 보호)
**규칙: `tools/measure/session.ps1`과 측정 스크립트를 네가 직접 실행하지 않는다**(Start/Stop 모두, 시험용도 금지). `-DryRunStdout` 모드만 실행 가능.
`tools/measure/session.ps1`을 고친다:
1. Start: `workbench-gpui` 프로세스가 하나라도 떠 있으면 백업·초기화를 **시작하지 않고** 오류로 끝낸다(사용자 데이터 손대지 않음).
2. Start: 백업을 다 쓴 뒤 해시 검증이 끝나야 초기화한다. 백업이나 앱 기동이 실패하면 즉시 원래 데이터로 되돌리고(이미 초기화했다면) 오류 — 실패 시 사용자 앱 데이터가 원래 상태여야 한다.
3. Stop: 앱이 떠 있으면 복원하지 않고 오류(지금처럼). 복원 뒤 원본 해시와 **바이트 동일 확인**이 된 뒤에만 백업 폴더 정리를 허용하는 함수를 두고, 그 외 어디서도 백업 폴더를 지우지 않는다. 측정 스크립트들(order0x-*.ps1)에서 백업 폴더를 지우는 코드를 찾아 없앤다.
4. settings.json·keymap.json도 같은 백업·복원 대상에 넣는다(지금 스크립트별로 따로 하던 것을 session.ps1로 모은다).
5. 측정 스크립트들의 session 호출은 출력 파이프로 기다리지 않는 한 가지 방식(order06-r1-v3.ps1에서 성공한 방식)으로 통일하고, 앞 단계 생략(-Steps) 때도 공통 전제(프로젝트 열기)를 수행하게.
정적 점검(문법·dry-run). 보고 `specs/v0.5/cards/C-30.report.md`(바뀐 조건, 실패 시나리오별 데이터 상태 표). 답은 결론 한 줄.
