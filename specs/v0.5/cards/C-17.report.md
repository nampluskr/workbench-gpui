## 2. 측정 스크립트 설계 및 단계 (`tools/measure/order04-v3.ps1`)

`tools/measure/order03-v3.ps1`의 검증된 네이티브 제어 및 레이아웃 덤프 파싱 기반을 재사용하여 안전하고 독립적인 `tools/measure/order04-v3.ps1`를 신규 작성했다.

### 2.1 스크립트 실행 단계
1. **`I20-tree` (앱 그림 — I-20 판정 대상)**:
   - 트리의 `branch \ nested` 압축 폴더 행을 탐색하고 전체 화면 캡처(`app-I20-tree.png`).
   - 로그에 `tree-row-01` 크롭 바운즈 기록 (`\` 일치 여부 확인용).
2. **`I20-tooltip` (앱 그림 — I-20 판정 대상)**:
   - `branch \ nested` 행 중심 좌표로 커서를 이동하여 툴팁(`D:\...\branch\nested`)을 띄운 뒤 캡처(`app-I20-tooltip.png`).
   - 마우스를 (5, 5)로 치워 툴팁 해제.
3. **`I20-dialog-unsaved` (OS 네이티브 — I-20 판정 제외 / OS 표시 기록)**:
   - 파일 열기 → 1자 수정(dirty) → `Ctrl+W`로 TaskDialog 팝업 탐지 → 대화상자 캡처(`app-I20-dialog-unsaved.png`) → `Esc` 전송으로 즉시 취소 → `Ctrl+Z` 복원 후 탭 닫기 (안전 보장).
4. **`I20-dialog-delete` (OS 네이티브 — I-20 판정 제외 / OS 표시 기록)**:
   - fixture 내 `file-001.txt` 선택 → `Delete` 키로 삭제 확인 TaskDialog 팝업 탐지 → 대화상자 캡처(`app-I20-dialog-delete.png`) → `Esc` 전송으로 즉시 취소 (실제 삭제 절대 수행 안 함).
5. **`I20-title` (앱 그림 — I-20 판정 대상)**:
   - 타이틀 바 `title-folder-name` 프로브 영역 캡처(`app-I20-title.png`) 및 크롭 바운즈 기록.
6. **`S-9-5digit` (ORDER-03 남은 1건 재측정)**:
   - 10,050줄 마크다운 픽스처(`01-order03-5digit.md`) 열기.
   - **문서 로드 폴링 (최대 20초)**: `Ctrl+End` 전송 후 임시 캡처를 떠서 거터 영역(줄 번호)의 잉크 상태를 분석.
   - 비어있지 않은 줄 번호 행 수가 20행 이상이고 잉크 가로 폭이 38px 이상(5자리 숫자 너비)일 때만 "로드 완료(OK)"로 판정.
   - 판정 통과 시 최종 `app-S-9-gutter-5digit.png` 캡처 저장. 20초 초과 시 단계 실패로 기록.
   - `Ctrl+W`로 5자리 탭 닫기.

### 2.2 안전 및 격리 규칙
- **Zed 미실행**: Zed는 구동하지 않으며 (`Only=App`), 사용자 창을 일체 건드리지 않는다.
- **프로세스 격리**: `session.ps1`이 반환한 `session.json`의 단일 PID만 추적하여 작업 종료 후 정상 종료(`CloseMainWindow`) 또는 강제 종료한다.
- **환경 복원**: `finally` 블록에서 `session.ps1 -Action Stop`을 호출하여 백업된 사용자 AppData 및 픽스처 폴더를 100% 원복한다.
