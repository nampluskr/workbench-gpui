3. **아이콘 테마 복사본**: fetch 스크립트에 `catppuccin/zed-icons` v1.24.0(실제 commit fe864c992c5da1e417e5897b741b7de9b90830e0)의 LICENSE·extension.toml·`icon_themes/`·`icons/`(5,248개 SVG, 8개 테마: Latte·Frappé·Macchiato·Mocha와 각 Monochrome) → `resources/zed-icon-themes/catppuccin-icons/`. Zed (Default)는 Zed 4304dec의 `crates/theme/src/icon_theme.rs`를 TEMP sparse checkout으로 읽어 연결표(stem 5·suffix 291·아이콘 92)만 아이콘 테마 JSON(`resources/zed-icon-themes/zed/zed.json`)으로 다시 썼다. Rust 코드는 복사하지 않았고 JSON에 출처를 `source`로 남겼다. 아이콘 경로는 Phase 5 `resources/zed-icons/file_icons/`를 가리킨다. 스크립트를 실제로 돌려 확인했다(네트워크 성공).
4. **아이콘 대응**(`icon_theme.rs`): 이름 전체 → 점으로 나눈 접미사 순서대로 → 첫 점 앞 stem 순서로 `file_stems`/`file_suffixes`를 찾고, 키가 없으면 `default`. 테마에 없는 키는 Zed (Default)로 폴백. 폴더는 `named_directory_icons[이름]`, 없으면 `directory_icons`. 대응 표는 전부 데이터(테마 JSON)이고 코드는 조회만 한다. 아이콘 경로는 JSON이 있는 번들 폴더 기준(Zed와 같음)이며 `res/` 에셋 접두사로 `resources/` 아래 `.svg`만 읽는다(`..`·루트·드라이브 경로 거부, 테스트함).
5. **파일 트리**: `panel_view::row_icon`이 아이콘 테마로 파일·폴더 아이콘을 그린다(Phase 5 `IconName::File` 교체). 아이콘 테마 데이터가 없으면 이전 아이콘으로 폴백. Zed (Default)는 이전처럼 글자색 마스크, 그 밖의 테마는 `img`로 SVG 자체 색을 그린다. UI 아이콘(I-1)은 그대로.
6. **Settings**: Theme Name·Icon Theme Name 드롭다운이 선택기와 같은 목록(`theme::names()`·`icon_theme::names()`)이며 현재 값이 선택돼 있다. `icon_theme`이 값 검증을 거쳐 `Values`에 들어간다(전에는 기본값만 허용). 선택기가 저장한 뒤 열려 있던 Settings 창이 "Settings changed on disk"로 막히지 않게, 선택기가 쓴 텍스트와 디스크가 같으면 따라간다(`selector_write`).

1. **탭 아이콘**: Zed 기본값은 탭에 파일 아이콘이 없고, 지금 탭의 마크다운 `file_doc`은 미리 보기용 UI 아이콘이다. 카드의 "탭의 파일 아이콘"은 이것을 가리키지 않는다고 보고 바꾸지 않았다. 탭에 파일 아이콘을 새로 넣으려면 탭 레이아웃 실측값이 바뀌므로 leader 판단이 필요하다.
2. **스펙에 없는 값(추정 아님, `spec: none (app value)` 표기)**: 선택기 모달 너비 544px(키맵 모달과 같게), 목록 최대 높이 320px, 간격 8px — `metrics::selector`. Zed 실측값 확인 카드가 필요하다.
3. **테마 이름 중복**: "Catppuccin Latte/Frappé/Macchiato/Mocha"가 테마와 아이콘 테마 양쪽에 있다. 선택기·설정은 키(`theme`/`icon_theme`)가 달라 충돌하지 않고, Extensions는 범주로 구분한다.
4. **테스트 범위**: gpui 테스트 컨텍스트(`gpui::test`)는 `Cargo.toml`에 `test-support`가 없어 쓸 수 없고 의존성 변경 금지라, 미리 보기·Esc 복원의 `App` 경로는 코드 확인이다. 대신 로직을 순수 함수로 나눠 테스트했다: 검색 일치·순서, 선택 순환, 이름·키 목록, theme·icon_theme 저장·검증·주석 보존·잘못된 이름 거부 시 파일 불변, 아이콘 대응(확장자·stem·여러 점·폴더·Catppuccin 파일 존재·경로 탈출 거부), extension.toml 읽기(`toml` 크레이트와 대조), Extensions 카드 manifest 값. 테스트는 K-19와 마찬가지로 복사본이 있어야 통과한다(`pwsh -NoProfile -File tools/fetch-zed-themes.ps1`).
5. **다이얼로그 동작 미확인**: Esc·바깥 클릭·Input의 ↑↓/Enter가 gpui-kit Dialog 안에서 기대대로 도는지는 코드(gpui-component 0.8.1) 읽기로만 확인했고 실행하지 않았다. V3에서 먼저 볼 항목이다. 한 번 더 Toggle 해도 다른 다이얼로그가 열려 있으면 겹쳐 열지 않는다.
6. 복사본이 없을 때: 기본 테마·기본 아이콘 이름만 유효하고 트리는 이전 아이콘으로 그려진다.
