설정 저장은 전체 JSON 재직렬화를 없애고 요청 키의 AST 값 범위만 교체한다. 없는 키는 첫 속성 앞(빈 객체는 닫는 괄호 앞)에 추가하고 나머지 원문은 보존한다. 중복 키는 같은 키의 값만 모두 갱신한다. 주석·한글·기존 CRLF·미지 키·후행 쉼표 보존, 빈 객체 삽입, 잘못된 파일 저장 거부를 테스트했다. 기존 잘못된 키가 있어도 다른 키의 저장이 가능하다. 잘못된 키만 기본값으로 적용하고 유효한 다른 키는 적용한다. 파일 원문에 있는 잘못된 값은 임의로 덮어쓰지 않는다. 시작 뒤와 외부 변경 시 기존 앱 알림에 오류를 표시하며, Settings 저장 오류는 기존 화면의 오류 자리에 표시한다.
