## 3. 연결 (같은 문법 · 다른 쿼리 폴더)

| 언어 id | grammar | 쿼리 폴더 | 쿼리 |
|---|---|---|---|
| javascript | TSX (`LANGUAGE_TSX`) | `javascript/` | H I O |
| tsx | TSX (`LANGUAGE_TSX`) | `tsx/` | H I O |
| typescript | `LANGUAGE_TYPESCRIPT` | `typescript/` | H I O |
| python | python | `python/` | H I O |
| yaml | yaml | `yaml/` | H I O |
| jsdoc (숨김) | jsdoc | `jsdoc/` | H |
| regex (숨김) | regex | `regex/` | H |
| zed-keybind-context (숨김) | rust | `zed-keybind-context/` | H |

- `grammar()`가 id별로 고르고 쿼리는 id 폴더에서만 읽으므로 JavaScript와 TSX가 같은 문법을 써도 쿼리는 섞이지 않는다. `load_queries`에 H 전용 목록(`jsdoc`·`regex`·`zed-keybind-context`)을 추가했다.
- 숨김 언어 3개는 suffix·first_line이 없어 `language_for_path`가 절대 고르지 않는다(주입용 등록만). K-42A 표 그대로.
- Zed 쿼리의 `(?s)`·`(?i:sql)` 같은 정규식은 변환 없이 `Query::new`가 받는다: 8개 언어의 쿼리 전부(Python·JS·TS·TSX·YAML의 H/I/O 15개 + 숨김 3개의 H 3개) 컴파일 성공(`copied_queries_compile_and_parse`).
- 기존 K-42A 단정 `grammar("python").is_none()`·`grammar("zed-keybind-context").is_none()`는 이제 거짓이라 대체했다: 모든 `LANGUAGES` id에 문법이 있고, JavaScript = TSX ≠ TypeScript, Zed Keybind Context = Rust, Env = Bash, JSONC = JSON 문법임을 `Language` 동등 비교로 확인(`grammar("javascript") == grammar("tsx")`).
