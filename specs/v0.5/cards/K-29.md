# K-29 — Replace는 버퍼만, 검색 툴바 뒤 아이콘 위치, 빈 화면 간격, toml ID 주석
**A. Replace 동작(데이터 동작 변경 — 가장 중요).** core-leader 참고: Zed는 Replace가 **열린 버퍼만 바꾸고 저장하지 않는다**(tauri도 같음). 지금 K-25 구현은 파일을 저장한다(`search_view.rs` "Replacement saved…"). Zed처럼 바꾼다: 대상 파일을 탭(버퍼)으로 열거나 이미 열린 탭 버퍼에 바꾸기를 적용하고, 탭은 수정됨(dirty) 상태로 남겨 사용자가 저장한다. 디스크에 직접 쓰지 않는다. 기존 데이터 보호(미저장 탭 충돌, 스냅샷 비교, 실패 시 중단)는 그대로 유지하고, 버퍼 기준으로 맞게 고친다. Replace Next(현재 일치 하나)·Replace All 둘 다. 안내 문구도 Zed 동작에 맞게(소스를 못 보면 문구를 지어내지 말고 기존 문구에서 "saved"만 빼고 보고에 적는다). 테스트: 바꾸기 뒤 파일 내용(디스크) 그대로·버퍼는 바뀜·dirty 표시.
