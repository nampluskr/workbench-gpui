# K-20 — 테마·아이콘 테마 선택기와 연결
1. "Select Theme…" 모달(`Ctrl-K Ctrl-T`, v → Themes…): 검색칸, 테마 목록(원본 이름), 지금 테마 체크·강조, 위아래 이동 시 미리 보기, Enter/클릭 적용·`settings.json` `theme` 저장(K-13 저장 방식), Esc 원래 테마로. 아래 `Install Themes` → Extensions 탭 Themes 범주.
2. "Select Icon Theme…" 모달(v → Icon Themes…): 같은 모양·동작, `icon_theme` 저장, 기본 Zed (Default). `Install Icon Themes` → Icon Themes 범주. 아이콘 테마 복사: `catppuccin/zed-icons` **v1.24.0**(LICENSE·extension.toml·아이콘 테마 JSON·아이콘) → `resources/zed-icon-themes/`(.gitignore), K-19 fetch 스크립트에 더한다. Zed (Default)는 Phase 5 `resources/zed-icons/file_icons/`와 Zed의 확장자→아이콘 대응(같은 커밋, 레포 밖 TEMP에서 대응 데이터만 읽어 정리 — 코드 복사 금지, 대응 표는 데이터로).
3. 파일 트리·탭의 파일·폴더 아이콘을 아이콘 테마로(확장자·파일 이름 대응은 그 테마 JSON). Phase 5의 `IconName::File`을 여기서 교체. UI 아이콘(I-1)은 그대로.
4. v 메뉴 Themes…·Icon Themes… 활성화, Settings 드롭다운을 전체 목록으로(선택기와 같은 값), Extensions 탭이 2장 확장과 기본 묶음을 manifest(`extension.toml` 복사본)로 보임.
테스트: 미리 보기·Esc 복원·저장, 아이콘 대응. 의존성 변경 금지. 앱 실행·커밋 금지. 확인 build·apply-manifest·test·clippy. 보고 `specs/v0.5/cards/K-20.report.md`. 답은 경로만.
