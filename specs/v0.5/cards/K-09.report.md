## 폴더 이름 중복 원인·수정

`title_bar::left_group`이 메뉴의 열림 상태와 무관하게 메뉴 view 뒤에 폴더 이름을 항상 추가했다. AppMenu의 열림 상태를 조회하고 관찰하여 타이틀 바를 다시 그리며, 열려 있는 동안 폴더 이름 요소를 제외한다. 닫히면 원래 이름/최근 프로젝트 안내가 돌아온다. 새 user-menu 요소를 추가한 타이틀 바의 layout probe 목록도 자식 순서에 맞췄다.

메뉴 이름 간격은 기존 NAME_GAP을 유지했다. `spec/zed-metrics.toml`의 `menu["horizontal.item_gap"]` I-321은 4px이고 현재 상수도 같은 값이다. 실제 화면 대조는 V3에서 한다.
