## 1. 바꾼 점 (`tools/measure/order03-v3.ps1`)

1. **선택 실행 매개변수 `-Steps` 추가**:
   - `param` 블록에 `[string[]]$Steps = @()` 추가.
   - 쉼표 또는 배열 형태로 전달된 단계명을 대소문자 무시 `HashSet`(`$normalizedSteps`)으로 정규화.
   - `-Steps`가 지정되면 자동으로 `$Only = 'App'`으로 고정되고 Zed 측정은 건너뜀.
2. **단계별 독립 디스패치 및 순서 보장**:
   - 측정 단계들을 `$stepActions` 맵과 `$stepTitles` 사전으로 구조화.
   - `-Steps`가 주어지면 호출자가 지정한 순서(예: `S-9-5digit,S-5-code`)대로 `$stepsToRun`에 적재하여 실행.
   - 별칭 해석 지원: `'S-5'` 지정 시 `'S-5-code'`로 매핑, `'S-9'` 지정 시 `'S-9-4digit'`, `'S-9-5digit'` 모두 실행.
3. **S-9-5digit (5자리 줄 번호 열 정밀 포커스 및 이동)**:
   - 이전 분할 상태 잔류 방지: `tab-bar` 폭이 800 미만(분할 pane)인 경우 `Ctrl+W`로 닫아 단일 pane 보장.
   - 파일 열기: 트리에서 `01-order03-5digit.md`를 찾아 더블 클릭 후 `active-item` 탐침 대기.
   - **확실한 에디터 포커스**: 레이아웃 덤프의 `active-item` 바운드 중심 좌표(`Get-BoxScreenCoord`)를 계산해 직접 클릭.
   - 끝으로 이동: `Ctrl+End`(VK_END `0x23`) 송신 및 600ms 대기 후 단일 pane 에디터 좌표 로깅.
   - 캡처: `app-S-9-gutter-5digit.png` 캡처 후 `Ctrl+W`로 5자리 탭 닫기.
4. **S-5-code (단일 pane 마크다운 미리보기 및 코드 블록 스크롤)**:
   - 단일 pane 보장: 분할 상태 시 단일 pane으로 복원.
   - `00-order03.md` 에디터 탭 활성화 확인 (`toolbar-btn-preview` 존재 여부 확인).
   - 미리보기 열기: `toolbar-btn-preview` 클릭 또는 `Ctrl+Shift+V` 단축키.
   - 분할 열림 대응: 미리보기가 새 분할 pane으로 열릴 경우 `tab-btn-zoom` 클릭 또는 `Ctrl-K Z`로 즉시 전체 화면 확대.
   - **코드 블록 뷰포트 내 스크롤**: `work-area` 내부로 마우스 이동 후 휠 아래로 4틱(-120 × 4) 회전하여 Section 4 코드 블록(`fn main()`)을 화면 중앙에 배치.
   - 캡처: 호환성을 위해 `app-S-5-code-block.png` 및 `app-S-5-markdown-preview.png` 모두 저장 후 `Ctrl+W`로 에디터 복귀.
5. **장애 격리 및 프로세스 정리**:
   - `Invoke-MeasureStep`의 `try ... catch`를 통해 개별 단계에서 단언 실패가 발생해도 다음 단계로 정상 진행.
   - `finally` 블록에서 자신이 시작한 프로세스 PID(`$appPid`)만 `CloseMainWindow` / `Kill`로 정리.
   - `session.ps1 -Action Stop`을 호출하여 `AppData` 및 픽스처 디렉터리 완벽 복원.
6. **Zed 격리 및 `-a` 제거 재확인**:
   - `Run-ZedMeasure` 시작부에 `if ($normalizedSteps.Count -gt 0) { return }` 가드 추가.
   - 메인 실행 루프에서도 `$normalizedSteps.Count -eq 0`일 때만 Zed 호출.
   - Zed 실행 시 `-a` 옵션이 완전히 제거되고 `-n` 독립 창 내 `Alt+2` 탭 전환 구조 유지 확인.
7. **DryRun 모드 강화**:
   - `active-item`, `toolbar-btn-preview`, `work-area` 상자 좌표 파싱 및 중심 좌표 계산 출력.
   - `-Steps` 정규화 목록 및 Zed 비실행(스킵) 여부 진단 출력.
   - `$outDir` 미지정 시 `Join-Path` 빈 문자열 예외 처리 보완.
