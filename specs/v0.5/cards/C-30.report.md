## 1. 개요 및 주요 변경 내역

사용자 앱 데이터(APPDATA\workbench-gpui) 보호를 강화하기 위해 `tools/measure/session.ps1` 및 측정 스크립트(`order03-v3.ps1`, `order04-v3.ps1`, `order05-v3.ps1`, `order06-v3.ps1`, `order06-r1-v3.ps1`, `order06-r2-v3.ps1`)를 정밀 수정했습니다.

1. **Start 안전 가드 최우선 배치 (`session.ps1`)**:
   - `workbench-gpui` 프로세스가 1개라도 실행 중이면 백업 디렉터리 생성이나 AppData 접근을 일체 수행하지 않고 즉시 예외 종료(사용자 데이터 보호).
2. **백업 원자성 및 트랜잭션 롤백 보장 (`session.ps1`)**:
   - 원본 AppData의 전체 파일(`settings.json`, `keymap.json`, `state.json*` 등 포함)을 백업한 뒤, 백업된 파일들의 SHA256 해시와 바이트 길이가 원본과 100% 동일함을 전수 검증한 뒤에만 초기화 진행.
   - 백업 완료 후 초기화, 픽스처 생성, 앱 기동 중 단 하나라도 실패하면 즉시 `catch` 블록에서 프로세스/픽스처를 정리하고 AppData를 원래 상태로 100% 롤백 복원.
3. **Stop 시 바이트 동일 검증 및 백업 정리 함수 제한 (`session.ps1`)**:
   - 앱이 실행 중이면 복원하지 않고 즉시 오류.
   - 복원 후 원본 해시와 바이트 단위 길이/해시 동일 확인이 통과된 경우에만 성공 판정. 불일치 시 백업 폴더를 영구 보존하고 오류 발생.
   - 복원 뒤 원본 해시와 바이트 동일 확인이 완전히 통과된 뒤에만 백업 폴더를 지울 수 있는 안전 함수 `Remove-BackupSafely`를 정의하고, 그 외 어디서도 백업 폴더를 지우지 않음.
   - 측정 스크립트들에서 백업 폴더를 임의로 지우는 코드가 없음을 전수 확인.
4. **settings.json·keymap.json 백업/복원 일원화**:
   - 기존 `order06-r1-v3.ps1` 및 `order06-r2-v3.ps1`에서 스크립트별로 분산 구현하던 `Backup-AllAppData` / `Restore-AllAppData`를 `session.ps1`의 공통 백업/복원 파이프라인으로 일원화.
5. **session 호출 방식 통일 및 공통 전제(프로젝트 열기) 보장**:
   - 측정 스크립트(`order03`, `order04`, `order05`, `order06`, `order06-r1`, `order06-r2`)의 session.ps1 호출 방식을 출력 파이프(`| ForEach-Object`) 없는 변수 캡처 방식(`$stopOutput = & ... 2>&1`)으로 전면 통일(자식 프로세스 표준 핸들 상속에 따른 행/대기 문제 완벽 차단).
   - 앞 단계 생략(`-Steps` 또는 `-Skip`) 시에도 메인 단계 실행 전 항상 `Ensure-ProjectTreeOpen $appHwnd $Out | Out-Null`을 호출하여 공통 전제(프로젝트 열기)를 보장.

## 2. 바뀐 조건 상세

| 대상 | 기존 상태 | 변경 후 상태 |
|---|---|---|
| **Start 프로세스 확인** | 백업 디렉터리 생성 전 단일 확인 | 백업 디렉터리 생성 및 파일 접근 전 최우선 프로세스 개수(`Count -gt 0`) 검사, 존재 시 무조건 throw |
| **Start 백업 검증** | 복사 후 해시 검증 없음 | 복사 완료 후 백업 폴더의 파일 목록, SHA256 해시, 바이트 길이 전수 대조 후 일치 시에만 초기화 |
| **Start 기동 실패 롤백** | 실패 시 AppData가 초기화된 상태로 방치될 위험 | `try-catch` 트랜잭션 롤백: 초기화/픽스처/기동 실패 시 즉시 AppData를 백업에서 100% 원복 |
| **백업 대상 범위** | `keymap.json`, `state.json*` 중심 | `settings.json`, `keymap.json`, `state.json*` 및 AppData 전체 파일 통합 |
| **Stop 복원 검증** | 단순 파일 해시 일치 확인 | 원본 해시 + 바이트 길이 + 파일별 스트림 해시 전수 동일 검증 |
| **백업 폴더 정리** | 별도 통제 없음 | `Remove-BackupSafely` 함수 내에서만 해시/바이트 동일 확인 후 조건부 삭제, 그 외 일체 삭제 금지 |
| **스크립트 session 호출** | 일부 스크립트에서 파이프 `\| ForEach-Object` 사용 | `$stopOutput = & ... 2>&1` 및 `foreach ($line in $stopOutput)`로 통일 (행 방지) |
| **공통 전제(프로젝트 열기)** | 일부 스크립트에서 스텝 루프 내 의존 | 모든 측정 스크립트에서 스텝 루프 진입 전 `Ensure-ProjectTreeOpen` 공통 수행 |
