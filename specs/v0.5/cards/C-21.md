# C-21 — Zed "v" 메뉴 확인 스크립트, pane 축소 아이콘 재측정

`D:\projects\workbench-core\specs\v0.5\orders\ORDER-06.md` 4장 읽기. leader가 화면 차례 안에서 실행할 `tools/measure/order06-v3.ps1`(order05 스크립트 재사용)을 쓴다.

## A. Zed "v" 메뉴 (`zed -n` 새 창만, 기존 Zed 창·설정 건드리지 않음, `-a` 금지, 띄운 창만 WM_CLOSE)
- 파일 하나를 연 새 창에서, "v" 버튼(타이틀 바 오른쪽 최소화 앞)을 클릭해 메뉴를 열고 캡처(항목·단축키 표시), Panel Layout 하위 메뉴도 열어 캡처, Esc.
- 여섯 항목 각각을 **단축키 또는 메뉴로 열고** 1~2초 뒤 캡처 → 무엇이 열렸는지(새 탭/새 창/모달/하위 메뉴) 판단할 수 있게 창 목록(새 HWND 생김 여부)·캡처를 남긴다 → 닫기: 모달·피커는 **Esc만**(Enter 금지 — 테마 피커에서 Enter는 사용자 설정을 바꾼다), 새 탭은 Ctrl+W, 새 창은 그 HWND만 WM_CLOSE.
  - Settings `Ctrl-,`, Keymap `Ctrl-K Ctrl-S`, Themes `Ctrl-K Ctrl-T`, Icon Themes(메뉴), Extensions `Ctrl-Shift-X`(설치 금지, 화면만), Panel Layout(하위 메뉴 항목만 캡처, 항목은 누르지 않는다 — 레이아웃 바꾸면 사용자 Zed 상태가 바뀐다).
  - 각 화면에서 스크롤·클릭 없이 첫 화면만. 설정·키맵 값은 바꾸지 않는다.
- 실행 전후로 Zed 설정 파일(`%APPDATA%\Zed\settings.json`, `keymap.json`)의 해시를 로그에 남겨 바뀌지 않았음을 확인한다(읽기만).

## B. 앱 pane 축소 아이콘 (ORDER-05 남은 1자리)
- 앱에서 파일을 연 뒤 Shift-Escape(앱 키맵에서 `workspace::ToggleZoom` 바인딩을 확인)로 확대 상태 진입 → 탭 바 확대/축소 버튼 자리 확대 캡처(`minimize.svg`) → 다시 Shift-Escape. Zed 같은 자리 캡처도(A의 창에서).
- 창 크기는 `Ensure-ClientSize`. 띄운 PID만 닫기, session Stop 복원.
