# K-04-R1 — I-7 고치기, I-13 현재 줄 배경 (줄 번호 색은 보류)

K-04 조사(`specs/v0.5/cards/K-04.report.md`)를 바탕으로 leader가 정했다.

1. **I-7**: 조사대로 Editor 자체 테두리·radius를 끈다(`refine_style` 등 gpui-component가 이미 공개한 방법). pane·탭·분할선 경계는 그대로. 한 줄·직각.
2. **I-13 배경**: `theme.highlight_theme.style.editor_active_line`을 현재 테마의 Zed 값(T-05.05, 표의 테마별 값)으로 둔다. soft wrap 줄 전체 강조는 엔진 기능 그대로 쓴다. 테마 값은 테마를 통해서만(AGENTS 5장). 지금 앱이 쓰는 테마가 무엇인지 확인해 그 값을 쓰고, 테마 전환이 있으면 테마별로.
3. **I-13 줄 번호 색은 이 카드에서 바꾸지 않는다.** 현재 동작(현재 줄 번호 = `theme.foreground`, 나머지 = `theme.muted_foreground`)을 그대로 둔다. 방향은 core-leader 답을 받은 뒤 따로 카드로 낸다. 공통 테마 색(`foreground`·`muted_foreground`)은 바꾸지 않는다.
4. 상호작용 테스트(`#[gpui::test]`): 커서 이동 → 강조 줄 이동, soft wrap 줄 전체 강조. `test-support` feature가 기본이 아니면 **Cargo.toml을 바꾸지 말고** 가능한 범위(로직 단위 `#[test]`)로 하고, 못 한 것은 보고에 적는다.
5. 의존성·Cargo 변경 금지, 앱 실행 금지, 커밋 금지. 확인: `cargo build`, `pwsh -NoProfile -File tools/apply-manifest.ps1`, 관련 `cargo test <filter>`, `cargo clippy --all-targets -- -D warnings`.
