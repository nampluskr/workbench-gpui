## 구현 및 테스트

- `SIDEBAR_ROW_GAP`을 6으로 바꾸고 focus border·right border·separator·icon slot 상수를 toml ID에 대응시켰다. `k39_sidebar_rows_match_spec`에서 높이·padding·테두리·아이콘·간격 9개 값을 `assert_spec`으로 대조한다. 기존 폭·footer 대조 테스트도 통과했다.
- 각 줄 바깥에 구분선용 wrapper를 두어 줄 자체의 높이 31과 포커스 테두리를 보존한다. 둘째 줄부터 wrapper에 위 border 1을 둔다. 폴더 내용·순서와 기존 이벤트 핸들러는 유지한다.
- `folder_row_colors`로 현재·없는 폴더·포커스 상태의 text/border 계산을 분리했다. 상태 조합 8개를 검사한다. 현재 폴더 배경과 hover 때 글자를 text로 바꾸던 스타일만 제거했다.
- gpui-kit 필드에 없는 색은 `SidebarColors` global에 저장하고 theme apply마다 교체한다. 기존 secondary 색은 다른 화면에 그대로 둔다. hover/active는 테마의 ghost 토큰, 없으면 동일 appearance의 One 토큰을 사용한다. 둘 다 없으면 기존 gpui-kit secondary 필드를 사용한다.
- `panel.focused_border`는 명시된 유효 테마 색을 우선한다. 없거나 null이면 appearance에 따라 다크 #2870bd·라이트 #0588f0이다. 기존 `resolved_color`의 panel/pane 공통 #62adef 분기에서 panel을 분리했고 pane의 값은 유지했다. tauri의 과거 라이트 border.focused 대체 방식은 사용하지 않는다.
- 테마 테스트는 다크 누락·라이트 null·명시값 우선 및 catalog 각 테마의 명시 ghost 토큰을 검사한다. 기존 테마 테스트도 모두 통과했다.
