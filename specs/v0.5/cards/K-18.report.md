Settings 소제목과 행은 Theme(Theme Name·Icon Theme Name) → Buffer Font(Font Size) → UI Font(Font Size) 순서로 맞췄다. 행 문구는 tauri SPEC R-2의 Zed 문구 그대로 유지했다. 숫자는 기존 NumberInput의 붙어 있는 감소·증가 버튼을 사용하고 높이를 기존 28px 상수로 지정했다. 드롭다운은 chevron_up_down.svg로 교체했다. v 버튼 아이콘은 user_menu.button_icon_size(I-601)의 14px로 바꿨다.

Settings 창 생성 때 파일 원문과 존재 여부를 보관한다. 저장 직전 변경·생성·삭제가 있으면 저장을 거부하고 기존 알림과 화면 오류로 알린다. 정상 저장 뒤에는 원문 기준을 갱신해 같은 창에서 연속 변경이 가능하다. 주석·다른 키 보존과 잘못된 값 처리도 유지했다. 충돌 거부·디스크 보존·연속 저장·섹션 순서를 테스트했다.

Extensions는 이름·설명·작성자 AND 검색, 테마 소스 경로 → 같은 파일의 배열 순서 → 아이콘 마지막의 안정 정렬, 필터 뒤 순서 유지로 맞췄다. 빈 상태는 No extensions / No installed extensions / No uninstalled extensions이며 검색어가 있으면 ` that match "검색어"`를 붙인다. 버전이 있으면 v 접두사와 muted 색으로 표시하고 없으면 버전 요소를 만들지 않는다. 메타데이터는 해당 theme JSON 필드 우선, 없거나 빈 값이면 family 같은 필드를 사용한다. 현재 자원에는 해당 JSON 메타데이터가 없어 빈 값을 유지한다. 검색·정렬·빈 상태·메타데이터 우선순위·버전 표시를 테스트했다. 다른 레포의 코드는 복사하지 않았다.

생략·위험: 화면과 실제 입력은 미검증이다. Extensions 자원 목록 차이와 자동 읽기는 Phase 7에서 처리해야 하며, 이번에는 새 자원을 복사하거나 탐색하지 않았다.
