## 구현

`WINDOW_INITIAL_SIZE`를 1440×852로 추가하고 출처를 `core v0.5 ITEMS I-6`로 적었다. 유일한 `window_options` 호출부인 `run`에서 주 디스플레이의 작업 영역을 받아, 그 중심에 고정 크기의 windowed bounds를 설정한다. 최소 크기 360×240과 타이틀 바 설정은 그대로다. 주 디스플레이 조회 실패는 명시적인 오류 메시지로 중단한다(기존 gpui Windows 창 생성도 모니터가 없으면 실패한다).

gpui `Bounds::centered`는 작업 영역보다 큰 창을 `size.min(...)`으로 줄이므로 쓰지 않았다. `Bounds::centered_at`으로 크기는 유지한다. 작업 영역이 1440×852보다 작으면 창 일부가 영역 밖으로 나올 수 있다. 카드의 고정 크기를 유지한 결과이며, 화면에서는 아직 확인하지 않았다.

단위 테스트는 작업 영역 원점 (0, 0), 음수 x와 양수 y 오프셋, 창보다 작은 작업 영역을 다룬다. 크기·중심·최소 크기·OS 타이틀 바 숨김을 확인한다. 직접 좌표 계산이나 Windows API 호출은 추가하지 않았다.
