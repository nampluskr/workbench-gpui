# K-08-R1 — 창 제어 버튼은 Zed(Windows)처럼 Segoe 글리프로 되돌린다

leader 확인: 같은 커밋 `4304dec732a75505066de5ce2dbbfb2bec369498`의 `crates/platform_title_bar/src/platforms/platform_windows.rs`(16~39, 80~83행)에서 Zed는 Windows 창 제어 버튼을 SVG가 아니라 **글리프 글꼴**로 그린다: 글꼴 "Segoe Fluent Icons"(없으면 "Segoe MDL2 Assets"), 최소화 `\u{e921}`, 복원 `\u{e923}`, 최대화 `\u{e922}`, 닫기 `\u{e8bb}`. K-08이 쓴 `generic_*.svg`는 Linux용이라 Windows Zed와 다르다.
- 창 제어 버튼 4개를 K-08 이전의 글리프 방식(같은 글꼴 선택·같은 코드 포인트)으로 되돌린다. 기존 코드(K-08 전, `git show HEAD:src/ui/title_bar.rs`)를 재사용한다. 값만 참고하고 Zed 코드는 복사하지 않는다.
- K-08 보고 대응 표의 창 제어 4행을 "Segoe Fluent Icons 글리프(Zed Windows와 같음, 근거 위 파일)"로 고치고, "남은 비-Zed SVG 출처"에 이 자리를 "Zed도 같은 글리프를 씀"으로 적는다.
- 그 밖은 바꾸지 않는다. 확인: `cargo build`, `pwsh -NoProfile -File tools/apply-manifest.ps1`, 관련 테스트, `cargo clippy --all-targets -- -D warnings`. 앱 실행·커밋 금지.
보고: `specs/v0.5/cards/K-08.report.md` 끝에 "## K-08-R1". 답으로 그 파일 경로만.
