# C-16 — 남은 두 항목만 재는 짧은 모드

C-15 판정(`specs/v0.5/verify/reviews/measure-ORDER-03.md`)에서 판정 불가 2건:
1. 앱 5자리 줄 번호 열(66/101): 포커스 이탈로 Ctrl+End 미도달.
2. 앱 미리보기 코드 블록(Lilex 16, 줄 간격 ≈25.9): 분할 뷰포트에서 코드 블록이 화면 밖.
Zed 기준값은 이미 있다(tauri 실측 66/101, 코드 16/≈26; C-15에서 Zed 4자리 56/91 확인). **Zed는 다시 열지 않는다.**

## 고칠 것 (`tools/measure/order03-v3.ps1`)
- `-Steps S-9-5digit,S-5-code` 같은 선택 실행 매개변수(지정한 단계만, 앱만). 공통 전제(앱 기동·프로젝트 열기)는 그대로.
- S-9-5digit: 5자리 fixture를 **단일 pane**에서 연 뒤, 편집 영역을 클릭해 포커스를 확실히 주고(클릭 좌표는 덤프의 active-item 안) Ctrl+End, 포커스·줄 번호 5자리가 보이는지 덤프/캡처로 확인 후 캡처.
- S-5-code: 단일 pane에서 00-order03.md 미리보기를 연다(분할 아님 — 미리보기가 새 pane으로 열리면 그 pane을 확대(zoom)하거나, 미리보기 영역 안에서 휠로 코드 블록이 보일 때까지 스크롤). 코드 블록이 보이는지 확인 후 캡처.
- 실패해도 다른 단계로 넘어가고, 띄운 앱 PID만 닫고, session Stop으로 복원.
- 문법 검사·`-DryRunStdout`(run5 또는 이번 stdout)으로 좌표 계산 확인. Zed 함수는 이번 모드에서 호출되지 않음을 확인.
- `zed -a` 제거 확인(C-15에서 고쳤는지).
