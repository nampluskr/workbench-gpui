# K-44 — 언어 주입(injection): 마크다운 인라인·코드 블록, HTML 안 CSS·JS, JS regex·JSDoc 등
규칙: `specs/v0.5/SPEC.md` R-15 "주입" 절(Zed `syntax_map.rs` 1720~1746, `available_languages.rs` 218~239 — 값·규칙만, 코드 복사 금지). 계획 K-41 6장 K-44. 지금 상태: 각 언어 자기 highlights만(K-42B~K-43C).
1. 쿼리의 `#set! injection.language "<이름>"` 또는 `@injection.language` 캡처 글자(마지막 `.` 뒤만) → 언어 이름 또는 `path_suffixes` 항목과 대소문자 무시로 맞춤(숨김 언어 포함), 없으면 주입 안 함(바깥 색 그대로). `@injection.content` 범위를 원래 바이트 위치로. `injection.combined`는 같은 언어 조각을 한 문서로 묶어 파싱. 주입 층 안에서도 다시 주입(마크다운 → 코드 블록 → 그 언어의 주입).
2. 색: 주입 층의 캡처를 바깥 캡처와 함께 Zed 규칙(시작 순 쌓기, 맨 위 하나)으로 — Zed에서 주입 층 캡처가 바깥보다 위인지 확인해 그대로.
3. 성능: 편집 때 바뀐 범위의 층만 다시(어렵다면 한계를 `shortcut:`과 보고에, 큰 마크다운에서 입력이 느려지지 않을 것).
4. 마크다운: K-42B 보고 3장대로 인라인(굵게·기울임·코드 스팬·링크)이 이 카드로 칠해져야 한다. 펜스 info string 언어(`rust`, `ts`, `py` …)와 `html_block`, `---` 머리말 → yaml.
V1: 마크다운(인라인 강조, 코드 블록 rust·ts, 모르는 언어 → 평문), HTML(`<script>` JS, `<style>` CSS, `style="…"`), JS(정규식 리터럴 → regex, `/** */` → jsdoc), 편집 뒤 층 갱신, 언어 없는 주입은 생략.
확인: `cargo build`, `tools/apply-manifest.ps1`, 관련 테스트, `cargo clippy --all-targets -- -D warnings`. 앱 실행·커밋 없음. 의존성 추가 금지. 보고 `specs/v0.5/cards/K-44.report.md`. 답은 경로만.
