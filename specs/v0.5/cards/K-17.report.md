Action은 `pane: close active item` 형식이며, 원래 이름과 읽기 쉬운 이름을 함께 검색하고 공백으로 나눈 검색어는 AND로 적용한다. 키는 `Ctrl-K Ctrl-S`, 빈 Context는 `<global>`, 인자 없는 값은 `<no arguments>`, null 액션은 `<null>`, 배열 액션의 인자는 JSON으로 표시한다. 사용자 원문에서 배열·null을 읽으므로 실행 파서가 적용하지 않는 배열 인자도 표에서 확인할 수 있다.

편집 모달은 폭 544px·본문 gap 10px·바닥 gap 4px를 스펙에서 가져왔다. Action은 등록 액션을 검색·선택하는 자동완성을 사용하며 `<null>`도 선택할 수 있다. Record는 기존 키를 비우고 새 입력을 받으며 최대 3타에서 끝나고 포커스를 잃거나 모달을 닫으면 중단한다. 배열 인자의 GUI 편집은 tauri와 같이 거부하고 JSON 편집을 안내한다.

모달을 열 때 원문과 파일 존재 여부를 보관한다. 저장 직전 디스크와 비교해 변경·생성·삭제가 있으면 저장을 거부하고 기존 앱 알림 및 모달 오류로 알린다. Keymap Editor의 기존 탭 검색은 현재 작업 공간으로 제한했다. 공유 helper를 사용하는 Extensions의 기존 검색 범위는 유지했다.

추가 테스트: 표시 형식·AND 검색·원래 이름 검색·빈 검색·JSON 인자·null·global, 녹화 최대 3타, 디스크 변경·생성·삭제 시 거부 및 바이트 보존, 충돌 없는 저장과 null 재읽기. tauri 구현은 동작 확인에만 참고했고 코드를 복사하지 않았다.
