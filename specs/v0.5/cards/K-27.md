**Project Search**
1. 툴바: 높이·아래 경계선이 Zed와 같게(Zed 툴바 y 65–109 부근, 아래 border). 왼쪽 접기/펼치기 아이콘, 검색 입력(둥근 테두리, 안 오른쪽에 Aa·wd·.*), 필터·바꾸기 토글, 이전/다음은 화살표가 아니라 **‹ ›** 모양(Zed 아이콘 이름 확인), 그 뒤 결과 수 `0/0`(작고 muted). **"Search" 글자 버튼은 Zed에 없다 — 지운다**(Enter로 검색).
2. 입력 칸 글꼴: Zed 자리표시 `Search all files…`·`Include: e.g. src/**/*.rs`·`Replace in project…`는 버퍼(고정폭) 글꼴이다.
3. 둘째 줄(Replace / Include·Exclude): 검색 입력 왼쪽 끝에 맞춰 시작, Replace는 검색 입력과 같은 폭, Include·Exclude는 그 폭을 둘로 나눔. 오른쪽에 아이콘 버튼(바꾸기: replace_next·replace_all / 필터: Only Search Open Files·Also search ignored 토글 **아이콘** — 가운데 정렬 글자 버튼이 아니다, 툴팁은 유지).
4. 빈 화면: 블록은 가운데지만 줄은 왼쪽 정렬. 제목 `Search All Files`(더 큼), 부제 muted, 각 줄 = 아이콘 + 이름 + muted 키(아이콘과 글자 사이 간격).
5. 결과: 파일마다 머리 줄(둥근 테두리 띠, 접기 chevron, 파일 이름 + muted **상대** 디렉터리 — 절대 경로 아님, 오른쪽 `Open File Alt-Enter` 버튼), 아래 발췌는 줄 번호 열·위/아래 펼치기 화살표 열, 일치 강조. 발췌 전체 회색 배경은 없다.
6. 상태 바 오른쪽: Zed는 결과 편집기 커서를 보여 준다(`45:35 (8 characters)`). 지금 앱은 입력 칸 커서(`2:39 (20 characters)`)를 보이는지 확인하고 Zed처럼 결과 편집기 기준이 되게(입력 칸 포커스일 때 Zed가 무엇을 보이는지 소스로 확인해 보고).
