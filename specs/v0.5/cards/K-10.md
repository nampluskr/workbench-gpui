# K-10 — 탭 순환 Previous Tab / Next Tab

core-leader 결정: gpui에 새로 만든다. action 이름은 Zed와 같은 `pane::ActivatePreviousItem` / `pane::ActivateNextItem`. 단축키는 tauri와 같게 — tauri 키맵(읽기만): `D:\projects\workbench-tauri\src\keymap\builtin.ts` 107·108행 `ctrl-pageup` → ActivatePreviousItem, `ctrl-pagedown` → ActivateNextItem; 메뉴 `D:\projects\workbench-tauri\src\shell\app-menus.ts` Go → "Previous Tab"/"Next Tab"(테스트 `app-menus.test.ts` 27행). Zed 기본 키맵(같은 커밋 `assets/keymaps/default-windows.json`, 레포 밖 TEMP에서 읽기)에 다른 바인딩도 있으면 보고에 적되, 이 앱에는 tauri와 같은 것을 넣는다.
- 동작: 활성 pane 안에서 앞·뒤 탭으로, 끝에서 처음으로(처음에서 끝으로) 돌아간다 — Zed 동작과 같게(같은 커밋 `crates/workspace/src/pane.rs`에서 확인, 코드 복사 금지). 탭이 하나거나 없으면 아무 일 없음.
- Go 메뉴에 "Previous Tab"·"Next Tab"을 Zed/tauri 순서 자리에 넣고 단축키 표시. K-09 메뉴 표를 갱신.
- 키맵 등록은 기존 키맵 구조(`src/keymap/`)를 따른다.
- 테스트: 순환(마지막→처음, 처음→마지막), 탭 1개.
- 의존성 변경·앱 실행·커밋 금지. 확인: `cargo build`, `pwsh -NoProfile -File tools/apply-manifest.ps1`, 관련 `cargo test <filter>`, `cargo clippy --all-targets -- -D warnings`.
