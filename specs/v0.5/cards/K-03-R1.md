# K-03-R1 — UI 글자 크기 되돌리기 (16은 rem 기준값이다)

## 판단 (leader)
ITEMS I-14 표의 "UI … 16"은 Zed `ui_font_size` 기본값 16, 즉 **rem 기준값**이다. 이 레포는 이미 rem = 16px다(`src/ui/rem.rs` L-01·L-02, `BASE_REM_PX`). Zed는 이 설정에서 요소별 글자를 rem 비율로 그리며, 우리 스펙의 12/14px(L-05 `typography["size.default"]`·`["size.small"]`, I-317, I-321, L-214, L-216, P-021 배너)는 그 Zed를 잰 값이다. 모든 UI 글자를 16px로 바꾸면 Zed와 달라진다. (core-leader에게 이 해석을 알렸다. 다르게 정하면 다시 알린다.)

## 할 일
1. K-03에서 바꾼 요소별 글자 크기를 모두 원래 값·원래 주석으로 되돌린다: `TEXT_SIZE_DEFAULT` 14, `TEXT_SIZE_SMALL` 12, `menu::ROW_TEXT` 14, `menu::NAME_TEXT` 12, `project_panel::BANNER_TEXT` 14, `tooltip::TEXT_SIZE` 14, `tooltip::META_TEXT_SIZE` 12, 그 밖에 K-03이 16으로 바꾼 곳 전부(`git diff`로 확인).
2. `menu_line_height_and_tab_content_equal_spec` 테스트를 원래 이름·기대값(`menu["item.line_height"]` 스펙 조회)으로 되돌린다. 테스트 기대값을 구현에 맞춰 바꾸지 않는다(AGENTS 9장).
3. `UI_FONT_SIZE`는 테마/창의 UI 글꼴 크기(= rem 기준 16) 한 곳에만 쓴다. 이 값이 실제로 rem(창 rem)과 일치하는지, 테마 `font_size`를 16으로 두는 것이 기존 요소 크기를 바꾸지 않는지 확인한다(gpui-kit 테마 `font_size`가 rem을 바꾸는지 소스로 확인; 바꾸면 16이 맞는지).
4. 글꼴 family(IBM Plex Sans/Lilex)·대체 순서·`calt` 끔·에디터 15/1.618·미리보기 제목 600·코드 Lilex·글꼴 파일은 그대로 둔다.
5. 확인: `cargo build`, `pwsh -NoProfile -File tools/apply-manifest.ps1`, `cargo test k03`, `cargo test menu_line_height_and_tab_content_equal_spec`, `cargo test ui::markdown_preview`, `cargo clippy --all-targets -- -D warnings`. 앱 실행·커밋 금지.
