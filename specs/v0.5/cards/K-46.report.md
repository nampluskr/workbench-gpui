| info | 결과 |

## 2. 색
- `code_block_runs(info, code)`: 블록마다 새 `SyntaxHighlighter`(편집기와 파서 공유 안 함)로 파싱해 `runs`를 구하고 색 없는 구간은 뺀다. 문법·쿼리·주입·테마가 편집기와 같다. 테스트: Rust 블록의 결과가 편집기 `runs`(색 없는 구간 제외)와 같고, `rust no_run`도 같으며, HTML 블록 안 `<script>`의 `let`이 주입된 JavaScript의 keyword 색, 모르는 언어·빈 코드는 빈 결과.
- 갱신: `TextView`는 하이라이터 `Arc`가 같을 때만 블록 결과를 재사용한다. 프레임마다 새 클로저를 만들면 매 프레임 다시 칠하므로 `code_block_highlighter()`가 `Arc` 하나를 돌려주고(테스트로 확인) `set_theme`가 비워 테마가 바뀌면 새 `Arc`가 되어 모든 블록이 다시 칠해진다.
