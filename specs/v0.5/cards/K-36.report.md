## 코드 확인

- 비어 있지 않은 `tab_list`는 `flex_1`로 가용 폭을 받고 `min_w_0`로 줄어들 수 있다. 각 탭의 `flex_shrink_0`은 유지한다. 끝 드롭 요소를 마지막 자식으로 추가하여 최소 24px은 스크롤 콘텐츠에만 포함한다. 비넘침 때는 기존 `flex_1` 드롭 요소가 남은 폭을 채운다.
- 빈 탭일 때는 기존 자리 표시 탭과 같은 드롭 요소를 flex 행 안에 두어 이전 표시와 남은 폭 채움을 유지한다.
- 바깥 탭 바 probe는 시작·탭 행·끝 버튼 3개에 맞춘다. 행 probe는 마지막 자식을 `tab-bar-filler`로 기록하고 나머지는 기존 `TAB_PROBES`로 기록한다. 따라서 탭 수가 12개 이상이어도 filler가 탭 probe 이름과 혼동되지 않는다.
- `pane_view.rs`의 유일한 `tab_bar` 호출은 그대로다. `end_drop`은 기존과 같이 `pane.tabs.len()` 위치로 이동시킨다. `TabScroll::follow(pane.active, tab_count)`와 `scroll_to_item(ix)`도 그대로다. 드롭 요소를 뒤에만 추가하므로 탭 인덱스 0..tab_count는 바뀌지 않는다. 관련 기존 활성 탭 스크롤·드롭 방향 테스트가 통과했다.
- 핀 탭 별도 행은 해당 없음: `pinned` 탭도 같은 `tabs.iter()` 행에서 렌더된다.
