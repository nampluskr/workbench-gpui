# K-02-R1 — 테스트 동어반복 고치기

checker C-06(`specs/v0.5/cards/C-06.report.md` 2장)이 지적했다: `initial_window_uses_work_area_center_and_fixed_client_size`가 `window_options`에서 더한 보정을 같은 식으로 빼서 비교한다(`(A+B)-B == A`). 보정 식이 틀려도 통과한다(AGENTS 4.4 위반).

## 할 일
- 테스트가 기대 오프셋을 **식이 아닌 손으로 쓴 값**으로 확인하게 고친다. C-06 2장의 예시(배율·frame_height별 `expected_offset_y` 리터럴: 8/1.0 → 4px, 9/1.25 → 3.2px, 13/2.0 → 3px)를 참고하되 값은 직접 다시 계산해 맞춘다. 정수 나눗셈(홀수 frame_height) 경우를 하나 포함한다.
- 가능하면 "gpui가 위에 배분하는 양 = frame_height/2(정수)" 가정도 주석 한 줄로 근거(gpui 파일·함수)를 남긴다.
- 코드 동작은 바꾸지 않는다. 확인: 그 테스트, `cargo clippy --all-targets -- -D warnings`. 앱 실행·커밋 금지.
