## 구현

- Project Search는 현재 열린 폴더 workspace마다 도구 탭을 사용한다. 폴더가 없으면 검색을 실행하지 않고 폴더 열기를 안내한다. 다른 workspace의 검색 탭을 잘못 재사용하지 않도록 기존 도구 탭 검색 범위를 검색·진단에도 현재 workspace로 제한했다.
- 검색 전 탭 제목은 돋보기 + `Project Search`, 검색 뒤 제목은 검색어다. 선택한 결과의 위치·선택 글자 수를 상태 바에 파일 형식 없이 보인다. 일반 편집 탭과 같은 파일 형식 표시를 도구 탭에 붙이지 않는다.
- 검색 입력 오른쪽 suffix에 Aa·wd·.* 토글, 밖에 Filters·Replace·이전/다음 결과·현재/전체 수를 배치했다. Enter로 검색하고 Alt-C/W/R/F 및 Alt-Shift-H로 옵션·줄을 전환한다. Alt-Enter·Open File·결과 클릭은 해당 파일의 일치 범위를 일반 편집 탭으로 열고 커서를 선택 끝에 둔다.
- Filters는 include/exclude glob, Only Search Open Files, Also search files ignored by configuration을 제공한다. ignore 토글은 기본 꺼짐이며 숨김 항목은 계속 제외한다. 열린 문서는 현재 메모리 내용을 검색하므로 미저장 편집도 검색 대상이다.
- `ignore`로 `.gitignore`·ignore 규칙과 glob을 적용하고 숨김·링크/reparse 항목을 제외한다. NUL 및 유효하지 않은 UTF-8 디스크 파일은 제외한다. UTF-8 BOM과 CRLF는 편집기와 같은 텍스트 위치로 정규화한다.
- 검색은 background executor에서 수행한다. 새 검색·Cancel·탭 drop은 기존 취소 토큰을 설정하고, 늦게 끝난 이전 검색 결과는 현재 검색을 덮지 않는다. 일치 파일 5,000개·일치 10,000개에서 제한을 표시한다(tauri 동작과 같은 상한). 읽기 실패는 메시지로 보이고 다른 파일 검색을 계속한다.
- 파일별 머리줄과 흐린 경로, 기본 앞뒤 2줄 발췌·줄 번호·일치 강조를 제공한다. 위/아래 화살표로 발췌를 추가로 펼칠 수 있다. 줄 인덱스를 캐시하고 결과 행은 GPUI 가상 목록으로 그려 전체 파일을 매 결과 렌더마다 훑거나 모든 결과 UI를 한꺼번에 만들지 않는다.
- 결과 이전/다음은 순환 선택하고 해당 발췌를 드러내며 상태 위치를 갱신한다. 파일별·전체 접기/펴기를 제공한다.

## Replace와 데이터 보존

- 다음 바꾸기·모두 바꾸기 모두 검색 당시 스냅샷과 현재 편집기 내용을 비교한다. 달라졌으면 재검색을 요구하고 변경하지 않는다. 정규식은 원본 문맥의 캡처를 사용해 교체 문자열을 확장하고, 일반 검색은 `$`도 그대로 취급한다.
- Replace All은 결과 한도에 포함된 일치 범위만 역순으로 바꾼다. 한도 때문에 표시되지 않은 나머지 일치를 몰래 바꾸지 않는다. 0폭 정규식 교체도 테스트했다.
- 파일을 기존 PaneGroup 경로로 열어 읽기가 끝나면 공유 뷰를 갱신하고 편집 상태를 표시한다. 실제 쓰기는 기존 `save_tab` 하나로 수행하므로 원래 인코딩·줄바꿈, 디스크 변경/삭제 확인, 저장 오류 처리를 재사용한다. 실패·취소 시 남은 배치를 중단하고 편집 탭을 확인하도록 안내한다. 성공 후 결과를 다시 검색한다. 외부 변경은 기존 저장 guard에서 다시 확인한다.
- 테스트는 생성한 임시 폴더의 데이터와 순수 교체 함수로만 수행했다. 앱을 실행하거나 사용자 파일에 검색·교체를 실행하지 않았다. 실제 저장 UI 흐름은 코드 확인이며 V3 대상이다.

## Diagnostics·라이선스

- 초록 check 아이콘 + `No problems` 탭, 접기·검색·스파클·새로고침·경고 아이콘 툴바, 중앙 `No problems in workspace`를 표시한다. 언어 서버나 가짜 진단 결과를 만들지 않았다.
- `ignore =0.4.34`, `regex =1.13.1`을 직접 의존성으로 추가했다. Cargo.lock diff는 workbench-gpui의 dependencies 목록에 두 이름을 더한 것뿐이며 기존 package 버전·checksum은 바뀌지 않았다.
- Licenses 창에 ignore의 MIT·Unlicense, regex의 MIT·Apache-2.0 원문을 추가했다. 원문은 해당 고정 버전의 로컬 crates.io 캐시에서 복사했다.
