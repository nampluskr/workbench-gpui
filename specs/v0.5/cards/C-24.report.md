## 1. 판정 요약

K-11(K-11-R1) 작업 결과물은 core ORDER-06-R1 (2.1, 2.4, 2.5), core D-15 및 core-leader Settings 공통안의 요구사항을 결함 없이 충족한다.

1. **설정 파일 읽기·쓰기 안전**: `%APPDATA%\workbench-gpui\settings.json` 경로에서 임시 파일(`.tmp`) 기록 후 `sync_all()` 및 Windows `ReplaceFileW` 기반 원자적 교체(`crate::state::win::replace_file`)를 수행한다. 파일이 없으면 기본값 `{}`로 처리하고, 잘못된 JSONC나 손상된 파일은 덮어쓰지 않고 보호하며, UI 수정 시 기존의 알 수 없는 키를 안전하게 보존한다. 미저장 상태의 설정 파일 탭은 앱 종료 시 확인 대상(`tab_close.rs`)에 포함되어 데이터 손실이 방지된다.
2. **즉시 적용**: UI 변경 또는 파일 감시(`keymap::watch`의 reload)를 통한 디스크 변경 시 `apply`를 통해 `Theme` 글꼴 크기(`font_size`, `mono_font_size`) 및 창의 rem/Editor text_size에 즉시 반영되며 `cx.refresh_windows()`로 모든 창이 다시 그려진다.

## 2. 세부 검토 내역

### 2.1 설정 파일 읽기·쓰기 안전 및 무손실 보장

- **없는 파일 처리 (`read`)**:
  - `std::fs::read_to_string` 결과가 `ErrorKind::NotFound`이면 빈 객체 `Ok(json!({}))`를 반환하여 기본값으로 안전하게 폴백한다.
- **깨진 파일 보호 (`read` & `save`)**:
  - 파일이 존재하나 JSONC 문법 오류가 있거나 최상위가 객체가 아닌 경우 `Err`를 반환한다.
  - `save()`는 `read()`가 성공한 뒤에만 새 값을 갱신하므로, 디스크에 이미 손상된 설정 파일이 있을 때 빈 파일이나 엉뚱한 값으로 덮어쓰지 않고 원본을 보존하며 UI에 오류를 알린다.
  - 입력된 글꼴 크기 숫자가 양수가 아니거나 유한하지 않은 경우(예: `-1`, `0`, `NaN`, `1e100`) 검증에서 즉시 거부되어 파일 쓰기를 차단한다.
- **알 수 없는 키 보존**:
  - `save()`는 파싱된 `raw: Value` 객체에 `raw[key] = value`로 해당 키만 수정하고 직렬화하므로, 주석 외에 사용자가 직접 추가해 둔 임의의 Zed 설정 키들이 유실되지 않고 유지된다.
- **원자적 쓰기 (`write`)**:
  - 대상 디렉터리가 없으면 `create_dir_all`로 생성한다.
  - 동일 디렉터리의 임시 파일(`settings.json.tmp`)에 기록한 뒤 `sync_all()`로 디스크 버퍼를 플러시하고 핸들을 닫은 후 `crate::state::win::replace_file`을 호출한다.
  - Windows `ReplaceFileW` API를 사용하여 정전이나 프로세스 비정상 종료 시에도 파일이 잘리거나 깨지지 않고 원자적으로 교체된다.
- **`Edit in settings.json` 및 종료 시 데이터 안전**:
  - 파일이 디스크에 없으면 빈 객체 `{}` 파일로 생성한 후 편집기 탭으로 연다.
  - 활성 폴더가 없는 상태에서도 전용 `settings_workspace`를 안전하게 생성하여 탭을 호스팅한다.
  - `src/ui/tab_close.rs:606`의 `Exit` 확인 루틴에 `self.settings_workspace`의 미저장 파일 검사가 포함되어 있어, 설정 탭을 편집하다 저장하지 않고 창이나 앱을 닫을 때 저장 여부를 묻는 대화상자가 정상 표시된다.

### 2.2 즉시 적용 (Immediate Application)

- **UI 조작 즉시 반영**:
  - 글꼴 크기 입력(`InputEvent::Change`) 또는 테마/아이콘 선택(`SelectEvent::Confirm`) 시 `save()` 성공 후 즉시 `apply()`가 호출된다.
  - `apply()`는 `Settings.values`를 갱신하고 `Theme::update`를 통해 `theme.font_size = px(ui_font_size)`, `theme.mono_font_size = px(buffer_font_size)`를 설정하며 `cx.refresh_windows()`를 호출한다.
  - 메인 창 및 설정 창의 `window.set_rem_size(settings::ui_size(cx))`와 편집기 탭의 `.text_size(super::settings::buffer_size(cx))`에 즉시 반영된다.
- **외부 파일 변경 감지**:
  - `src/ui/keymap.rs:540`의 앱 데이터 감시 루프에서 `settings.json` 변경 시 `settings::reload(cx)`가 호출된다.
  - 읽은 값이 현재 메모리의 값과 다를 경우에만 `apply()`가 발동하여 불필요한 재렌더링 없이 즉시 화면에 반영된다.
