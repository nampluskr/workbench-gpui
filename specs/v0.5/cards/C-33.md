# C-33 — Zed 확인 스크립트 (상태 바·Project Search·Diagnostics)
`tools/measure/order08-zed.ps1`(Zed만, 앱 안 띄움, 앱 데이터 백업 불필요). Zed 창은 order06-v3.ps1/order07-v3.ps1에서 성공한 함수로 `zed -n <폴더>` 새 창만(fixture 폴더는 스크립트가 `-Out` 아래 직접 만든다: 마크다운 하나, 코드 파일 몇 개, 같은 문자열 여러 곳), 실행 전후 Zed 최상위 HWND 차이로 찾고 자기 창만 WM_CLOSE. 사용자 Zed 설정 해시 전후 기록. Zed Settings는 열지 않는다.
단계(각각 캡처, 항목 독립):
1. 탭 없는 상태의 상태 바 전체 크롭(오른쪽 끝까지).
2. 파일 하나 열고 커서를 몇 줄 아래로 → 상태 바 오른쪽 크롭(`{line}:{column} {Filetype}` 위치). Shift+방향키로 선택 만든 뒤 크롭(선택 표시 형식). 다른 형식 파일(.rs, .json, .ts, .txt) 각각 열어 파일 형식 이름 크롭.
3. 상태 바 왼쪽 버튼들 확대 크롭, 각 버튼에 hover 1초 → 툴팁 크롭. 왼쪽 dock(프로젝트 패널) 열림/닫힘 두 상태 크롭(켜짐 표시).
4. 검색 버튼 클릭 → Project Search 탭 캡처(빈 상태), 검색어 입력 + Enter → 결과 캡처(발췌·결과 수), 옵션 버튼 영역 확대.
5. 진단(✓) 버튼 클릭 → Diagnostics 탭 캡처(문제 없을 때 문구).
6. 끝: 자기 창 WM_CLOSE(저장 대화상자 뜨면 닫지 말고 로그 — 파일은 수정하지 않으므로 안 뜸).
