## 2. 자동 줄바꿈

- 지금(바꾸기 전) 조건: **모든 편집기가 항상 줄바꿈** — `EditorState`의 `soft_wrap` 기본값이 `true`(`vendor/gpui-base/src/input/base/state.rs:952`)이고, 탭 편집기를 만드는 `pane_group.rs` `new_editor`는 이를 바꾸지 않는다. 레이아웃 때 `display_map.on_layout_changed(self.soft_wrap.then_some(wrap_width))`(`state.rs:782`)로 적용된다. 언어 구분이 없었고, 줄바꿈을 끄는 곳은 개발용 `--dev-no-wrap`(`editor_poc.rs:39`)뿐이다. 그래서 HTML·코드 파일이 모두 폭에서 줄바뀌었다.
- Zed 기본값(`assets/settings/default.json`, `4304dec`): 전체 기본 `"soft_wrap": "none"`(줄 1687), 언어별 덮어쓰기로 `"editor_width"`인 것은 **Markdown, Plain Text, Git Commit**(`languages` 절). 다른 언어(HTML·JSON·YAML·Python·Rust·…)는 덮어쓰기 없음 → 안 바뀜.
- 고침: `syntax::editor_settings(language_id)`: 언어 id가 `""`(어느 언어도 아닌 파일 = Plain Text), `markdown`, `gitcommit`이면 줄바꿈, 그 외는 안 함. `set_language`가 언어를 정하는 모든 지점(탭 열기·읽기 완료 `fill`·복사 탭·분할·이름 바꾸기 `refresh_languages`)에서 `apply_soft_wrap`을 호출한다. 마크다운은 기본값과 같아 호출 자체가 없고(SPEC R-8 유지), 코드 파일만 `false`로 바뀐다. `.txt`·확장자 없는 알 수 없는 파일은 줄바꿈(Zed Plain Text).
- vendor 변경 이유: `set_soft_wrap`이 `&mut Window`를 받지만 쓰지 않는데, 이름 바꾸기 경로(`panel_ops.rs`·`watch.rs`)에는 Window가 없어 같은 본문을 Window 없는 `apply_soft_wrap`으로 빼고 `set_soft_wrap`이 이를 부르게 했다(동작 동일). 현재 값을 비교하려고 `is_soft_wrap` getter 추가.
- 한계: 줄바꿈을 끄면 가로 스크롤이 생긴다(Zed 동일). 마크다운 미리보기 탭의 숨은 편집기는 이 함수를 지나지 않는다(기본값 유지).

## 3. 탭 표시 폭

- 지금: **2칸** — `TabSize::default()`가 `tab_size: 2`(`vendor/gpui-base/src/input/editor/indent.rs:20-27`), 이 앱은 설정한 적이 없다. 표시는 `element.rs:2169`(`state.mode.tab_size().tab_size`), `2705`(`display_map.set_tab_size`), `2938-2949`(`tab_stop_width`: tab_size × 글꼴의 공백 폭), `state.rs:780`.
- Zed: 전체 기본 `"tab_size": 4`(줄 1702), 덮어쓰기는 Dart 2·Elm 4뿐이고 둘 다 언어 표에 없다 → 모든 언어와 Plain Text가 4.
- 고침: `editor_settings(...).tab_size = 4`를 `set_language`가 `set_tab_size(TabSize { tab_size: 4, hard_tabs: false })`로 적용(새 탭은 `open`에서 바로 호출되어 처음부터 4). 파일 내용은 바뀌지 않는다. 부수 효과: Tab 키가 넣는 공백도 2칸 → 4칸이 된다(Zed `hard_tabs: false`와 같다).
- 알림: Zed는 Go에서 `hard_tabs: true`(Tab 키가 탭 문자를 넣음)인데 적용하지 않았다. 필요하면 별도 카드로.
