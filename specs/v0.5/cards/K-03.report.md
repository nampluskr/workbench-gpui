## 적용 지점과 판정 근거

- 앱 초기화 직후 글꼴 8개를 등록하고 공통 테마의 UI/mono family와 크기를 설정한다. UI 크기 원본은 `metrics::UI_FONT_SIZE` 한 곳이다.
- UI는 IBM Plex Sans → Segoe UI → Malgun Gothic, 에디터는 Lilex → Cascadia Mono → Consolas → Malgun Gothic 순서다. Workspace 루트와 별도 툴팁에 UI Font를 설정하고, 에디터·PoC·미리보기 코드에는 editor Font를 설정한다.
- UI의 기존 영역별 12/14px 상수는 I-14(카드 표, core D-12 우선)에 따라 모두 16px를 참조한다. 메뉴 줄 높이 테스트도 종전 14px 기준 I-317 대신 I-14의 16px × 기존 L-09 배수를 판정한다. 기대값을 임의로 낮추거나 테스트를 삭제하지 않았다.
- gpui-component 래퍼는 제목 크기만 공개하고 굵기를 공개하지 않아, 이미 의존 중인 gpui-base의 동일 TextView를 직접 사용한다. 기존 블록 처리, 선택, frontmatter, 테마 색상과 코드 강조용 전역 defaults를 유지하면서 제목에 SEMIBOLD를 지정한다. 새 의존성은 없다.
- 파일 등록 실패는 시작 시 명확한 오류로 중단한다. 파일·저장 로직은 바꾸지 않는다.
