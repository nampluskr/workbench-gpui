# INTENT — workbench-gpui v0.1

## 목적·범위·기대 결과

- 목적: PoC 1~3단계로 gpui-kit 위에 Zed 모양의 첫 화면(창·타이틀 바, 편집기, 레이아웃 뼈대)을 세우고, 직접 구현할 범위를 확정한다.
- 범위: 02-gpui 출발 문서 7절의 PoC 1~3단계.
  - 1단계: 빈 창, 커스텀 타이틀 바, 창 버튼, 앱 매니페스트.
  - 2단계: gpui-kit Editor PoC. 한글 IME, 한글 대체 글꼴, 큰 파일, 선택·커서, 줄 끝·인코딩.
  - 3단계: 레이아웃 뼈대. 사이드바·Dock·Pane·탭 바·상태 표시줄, rem 헬퍼.
- 기대 결과: 02-gpui 7절의 "끝났다고 보는 기준"을 따른다.
  - 1단계: 창의 스냅, 타이틀 바 더블클릭 최대화, 타이틀 바 높이를 확인했다.
  - 2단계: gpui-kit Editor로 할 수 있는 것과 직접 구현할 범위가 확정되었다.
  - 3단계: 레이아웃 뼈대의 치수가 명세의 치수 점검표와 맞는다.
  - 세부 수치와 항목 ID는 `SPEC.md`가 담는다.

## 배경

Herdr 구성과 루트 `INTENT.md` 작성을 마쳤다.
이제 02-gpui 출발 문서(D:\projects\docs\guides\zed-like-editor\02-gpui\README.md)를 바탕으로 구현을 시작한다.
