# INTENT — workbench-gpui v0.4

## 목적·범위·기대 결과

- 목적: v0.3에서 정리한 기반 위에서 세 가지를 한다.
  - v0.3에 남은 정리 항목과 동작 위험을 마저 고친다.
  - 화면과 에디터 코어를 Zed 실측값에 맞춘다.
  - 탭에서 파일을 편집하고 저장하며, Zed의 탭 기능(미리보기 탭·핀·분할·드래그)을 더한다.
- 범위: 사용자 결정(2026-11-04)대로 다음 일곱 가지다. 순서는 정리 → 일치 → 기능이다.
  - 정리
    - AUDIT 3: 붙여넣기·복제 실패를 사용자에게 알리고, 실패한 잘라내기 항목을 남긴다.
    - AUDIT 4: 큰 파일 첫 열기와 복사·이동이 UI 스레드를 막지 않게 한다.
    - v0.3 범위 밖에 남은 `Duration::from_*` 하드코딩(watch·keymap·dev·editor_poc·watch_io·mod)
    - clippy 기준선 경고 10개
  - 일치
    - 초안 P4 UI 셸 정리: 메뉴·아이콘·패널·타이틀 바·상태 표시줄을 Zed 실측과 일치시킨다. v0.3 스펙 불일치 목록(`sidebar["default_width"]` 300 대 375)을 포함한다.
    - 초안 P5 에디터 코어 정리: 버퍼·커서·선택·텍스트 레이아웃·IME·스크롤을 Zed 동작·실측과 일치시킨다.
  - 기능
    - 탭 편집과 저장: 편집, 저장, 저장 질문, 충돌 표시, 지워진 파일 탭 표시, 저장 때 확인창(v0.2 D-18에서 미룬 것)
    - PoC 6단계 탭 기능: 미리보기 탭, 핀, 분할, 탭 드래그, 마크다운 미리보기
- 기대 결과
  - AUDIT 3·4가 고쳐지고, 하드코딩 `Duration`과 clippy 경고가 0건이다.
  - UI 셸과 에디터 영역의 V3 실측 불일치가 0건이다.
  - 탭에서 파일을 편집·저장할 수 있고, 저장하지 않은 변경을 잃지 않는다.
  - 미리보기 탭·핀·분할·탭 드래그·마크다운 미리보기가 Zed와 같은 규칙으로 동작한다.
  - 의도한 변경 밖의 v0.2·v0.3 동작은 바뀌지 않는다.
  - 세부 항목과 판정 방법은 `SPEC.md`가 담는다.

## 배경

v0.3(ponytail 기반 리팩토링, Phase 0~3)을 마쳤고, 사용자가 종료를 결정했다(2026-11-04, `specs/v0.3/PROGRESS.md` "버전 종료"). 다음 버전 번호는 v0.4다(사용자).

v0.3 "남은 것"과 v0.2 "남은 것" 3(이후 버전으로 미룬 범위)을 재료로 사용자가 v0.4 범위를 골랐다(2026-11-04).
- 주 범위: "P4 UI 셸 Zed 일치, P5 에디터 코어 정리, 탭 편집과 저장, PoC 6단계 탭 기능"
- AUDIT 3·4: "둘 다 고친다"
- 정리 항목: "Duration 하드코딩, clippy 경고 10개"
- 진행 방식: "herdr 멀티 에이전트"
- Phase 순서: "정리 → 일치 → 기능"

v0.3까지는 동작을 바꾸지 않았다(v0.3 D-9). v0.4는 코드 값을 스펙 값으로 맞추고 기능을 더하므로 동작이 바뀐다. 그래서 동작 불변 대조(v0.3 R-12)는 "의도한 변경 밖의 동작은 그대로"를 보는 회귀 대조로 바꾼다(`DECISIONS.md` D-8).

- `docs/refs/01-zed/`: Zed 명세 원문. 탭은 01-LAYOUT 4.4, 02-INTERACTION 2·3절(`I-060~I-076`)
- `specs/v0.3/AUDIT.md` 3·4·6: 이번에 고칠 감사 항목

## 제외 범위

- PoC 7단계(테마·아이콘 테마 매핑과 선택기, 내장 테마 번들, Zed 글꼴 자산)와 8단계(찾기 창, Picker·Open Recent, 키맵 편집 화면, 확장, 그 밖의 상태 복원)
- 편집기 직접 구현 12건 가운데 큰 파일 + soft wrap 켜짐 열기(10만 줄 첫 프레임 7.6초). 나머지 11건은 P5(8건)와 탭 저장(인코딩 3건)에 든다(`DECISIONS.md` D-6·D-10).
- 에디터 직접 구현. gpui-kit Editor를 그대로 쓴다(D-6).
- 프로젝트 패널 드래그 앤 드롭(I-094)과 외부 드롭 뒤 자동 열기(I-097)
- 패키징·서명
- 큰 파일 분할(`folders.rs`·`dev.rs`), `watch.rs` epoch 함수 통합(v0.3 남은 것 5·6). 사용자가 이번에 고르지 않았다.
- v0.2 알려진 한계(정션 안 변경 미반영, 케이스 폴딩 등)와 휴지통 판정 불가 항목
- 지난 버전 폴더(`specs/v0.1/`~`specs/v0.3/`)의 수정
