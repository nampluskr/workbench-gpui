### 2.2 P2-2: 글자 크기 별칭 명시화 (`6949652`) — PASS

#### (1) 프레임워크 소스 분석 (`gpui-pre-0.3.10/src/styled.rs:545-555`)
gpui-pre 소스 확인 결과:
```rust
fn text_xs(mut self) -> Self {
    self.text_style().font_size = Some(rems(0.75).into());
    self
}
fn text_sm(mut self) -> Self {
    self.text_style().font_size = Some(rems(0.875).into());
    self
}
```
- `text_sm()`은 `font_size`를 0.875 rem (14px)으로 설정하고, 줄 높이(line_height)는 변경하지 않음.
- `text_xs()`는 `font_size`를 0.75 rem (12px)으로 설정하고, 줄 높이는 변경하지 않음.

#### (2) 명시 상수 교체 및 렌더 불변 대조
- `TEXT_SIZE_DEFAULT`: `rems_from_px(14.)` = `Rems(14.0 / 16.0)` = `Rems(0.875)`
- `TEXT_SIZE_SMALL`: `rems_from_px(12.)` = `Rems(12.0 / 16.0)` = `Rems(0.75)`
- 교체 대상:
  - `folders.rs`: 사이드바 행, 안내 화면 버튼, 안내 화면 본문 2곳 → `.text_size(super::metrics::TEXT_SIZE_DEFAULT)`
  - `layout.rs`: 탭 라벨 2곳 → `.text_size(TEXT_SIZE_DEFAULT)`, 상태 표시줄 1:1 라벨 → `.text_size(TEXT_SIZE_SMALL)`
  - `panel_view.rs`: 트리 행 라벨 → `.text_size(super::metrics::TEXT_SIZE_DEFAULT)`
  - `title_bar.rs`: 폴더 이름 버튼 → `.text_size(super::metrics::TEXT_SIZE_DEFAULT)`
- 교체 후 `src/` 전체에서 `.text_sm()` 및 `.text_xs()` 호출 검색: **0건**.
- `.text_size(...)` 호출 역시 `font_size`만 설정하므로, 렌더 결과(글꼴 크기, 행 높이, 줄 간격)가 100% 동일함.
