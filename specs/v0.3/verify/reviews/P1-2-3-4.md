## 2. 카드별 상세 검토

### 2.1 P1-2: 스펙 ID 조회 헬퍼 (`e6b6a87`) — **PASS**
- **Cargo 변경 범위**: `Cargo.toml`의 `[dev-dependencies]`에 `toml = "=1.1.8"` 1줄만 추가됨. `Cargo.lock`에는 이미 캐시되어 있던 `toml 1.1.8+spec-1.1.0`이 링크되어 신규 다운로드 0건으로 사용자 승인 조건 준수.
- **헬퍼 위치 및 구조**: `src/ui/metrics.rs` 내부 `#[cfg(test)] pub mod spec`에 배치되어 불필요한 파일 생성 방지(AGENTS 4장).
- **ID 파싱 및 조회**: `table["key"]` 형식을 정확히 분리하여 테이블 경로 순회 및 `Entry { value, unit, cond, src }` 반환.
- **오차 조회 (`tolerance`)**: `verification.tolerance["dimension"]`(±1.0 px)과 `verification.tolerance["font_size"]`(±0.5 px)를 스펙 파일에서 직접 동적으로 읽어오며, `px` 외 단위는 0.0(정확 일치) 적용.
- **글꼴 판별 규칙**: `id.starts_with("typography") && id.contains("size")`로 정확하게 글꼴 크기 항목에만 `font_size` 오차(0.5)를 적용.
- **실패 메시지 형식 (`layout-test-req.md` 4절)**:
  - 없는 ID: `spec id not found: {id} (spec/zed-metrics.toml)` (4절 규격 일치)
  - cond 불일치: `spec cond mismatch: {id} expected cond={expected_cond}, spec cond={}` (4절 규격 일치)
  - 값 불일치: `spec mismatch: {id} expected {value} {unit} (±{tol}, cond={cond}, src={src}), actual {actual} {unit}` (4절 규격 일치)
  - 메시지가 한 줄이고 영문이며 ID가 맨 앞에 오도록 구현됨.

  - gpui-kit의 `test-support` 의존성 추가 없이 순수 Rust built-in 테스트 러너를 사용하기 위해 `#[core::prelude::v1::test]`를 명시함. 코드에 주석으로 사유가 잘 명시되어 있음.
