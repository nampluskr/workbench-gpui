## 3. 결함 분석 (REWORK 사유)

### 결함 1: `session.ps1`의 `$Backup` 하드코딩된 기본값으로 인한 실행 불가 (Critical)
- **파일**: `tools/measure/session.ps1`
- **위치**: 3행, 18행, 66행
- **현상**:
  - `session.ps1` 3행의 파라미터 기본값이 `[string]$Backup = 'D:\projects\workbench-gpui\specs\v0.3\verify\reviews\_p0-6-backup'`로 하드코딩되어 있음.
  - 현재 워크스페이스에 `_p0-6-backup` 폴더가 이미 존재함.
  - 18행의 가드 `if (Test-Path $Backup) { throw 'Existing backup; do not overwrite' }`에 의해, `README.md`에 안내된 기본 실행 명령인 `pwsh -File tools/measure/session.ps1 -Action Start -Json -Out <dir>`을 실행하면 `-Backup`을 생략하게 되어 무조건 예외가 발생하고 스크립트가 중단됨.
  - 또한 `-Action Stop` 시에도 `README.md` 예시대로 `-Out <dir>`만 주면 기본값인 `_p0-6-backup`에서 `before.json`을 읽으려고 시도하게 되어, 새 측정 세션과 백업 폴더가 분리되지 못함.
- **기대 수정**:
  - `$Backup`이 지정되지 않았을 때 `$Out`에 연동되도록 수정 (예: `$Backup = if ($Backup) { $Backup } else { Join-Path (Split-Path $Out) ('_' + (Split-Path $Out -Leaf) + '-backup') }` 또는 `$Out` 하위/형제 폴더로 자동 유도).
  - `README.md`에도 백업 폴더 위치 및 동작 규칙이 일치하도록 반영.

### 결함 2: `input.ps1`의 `shortcut:` 주석 누락 (Minor)
- **파일**: `tools/measure/input.ps1`
- **위치**: 파일 상단 (1~2행)

- **기대 수정**:
