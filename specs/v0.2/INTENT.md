# INTENT — workbench-gpui v0.2

## 목적·범위·기대 결과

- 목적: 02-gpui 출발 문서 7절의 PoC 4~5단계로, 키맵·액션 체계를 세우고, 여러 폴더를 등록해 트리로 보고 파일 작업을 하는 데까지 간다.
- 범위: 02-gpui 7절의 PoC 4~5단계.
  - 4단계: 키맵 로더, 액션·컨텍스트, 툴팁·메뉴의 단축키 표시 (02-gpui G-105, G-111).
  - 5단계: 폴더 등록, 트리, 파일 작업, 감시 (01-zed A-10~A-17, I-087~I-097, 02-gpui G-115). 시나리오에 필요한 최소 탭 동작(D-9)과 등록 폴더 목록 저장·복원(D-10)을 함께 넣는다.
- 기대 결과: 02-gpui 7절의 "끝났다고 보는 기준"을 따른다.
  - 4단계: VSCode 덧씌움 결과로 메뉴·툴팁의 키가 일치한다.
  - 5단계: 시나리오 A-33.2, A-33.4 가 된다.
  - 세부 항목과 판정 방법은 `SPEC.md`가 담는다.

## 배경

v0.1(PoC 1~3단계: 창과 타이틀 바, 편집기 PoC, 레이아웃 뼈대)을 마쳤고, 사용자가 종료를 결정했다(2026-11-01, `specs/v0.1/PROGRESS.md` "버전 종료").
v0.2 범위를 PoC 4~5단계로 정한 것은 사용자 결정이다(2026-11-01). 같은 결정에서 편집기 직접 구현 12건은 이후 버전으로 미루고, Zed 글꼴 자산은 넣지 않기로 했다. 진행 방식은 v0.1 과 같다.
v0.1 "남은 것"에서 이번 버전에 가져오는 것은 없다. 남은 것은 아래 제외 범위와 `DECISIONS.md` 미결 사항에 이어 적는다.

- 편집기 직접 구현 12건 (`specs/v0.1/verify/phase2/POC-TABLE.md` R-11 요약, v0.1 "버전 종료"의 남은 것 1).
