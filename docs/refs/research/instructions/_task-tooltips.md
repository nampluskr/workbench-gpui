2. 우리 앱에 남기는 아이콘·요소마다 **정확한 툴팁 문구**와 함께 표시되는 액션/단축키:
   - 타이틀 바: ☰ 메뉴, 프로젝트(폴더) 이름 버튼, 최소화·최대화·복원·닫기 (Windows 창 버튼에 툴팁이 있는지)
   - 사이드바: 폴더 추가(L-96 "Add Project"?), 항목(폴더) hover 시, 사이드바 닫기 버튼 등 사이드바 안 아이콘
   - 탭 바: ← (뒤로) → (앞으로), 탭 hover(전체 경로 표시 여부), 탭 닫기 ×, 미리보기 탭, + (새 항목 메뉴), 분할, 최대화(줌)
   - 프로젝트 패널: 항목 hover(경로 툴팁 여부), 패널 상단/하단 아이콘
   - 상태 표시줄: 사이드바 토글, 폴더 추가, 프로젝트 패널 토글, 커서 위치(클릭 시 Go to Line 툴팁)
   - 테마 선택·아이콘 테마 선택 관련 버튼이 있다면
3. 각 문구의 출처(파일·줄). 문구가 상태에 따라 바뀌면(예: Toggle/Show/Hide, Zoom In/Out) 모든 경우를 적는다.
