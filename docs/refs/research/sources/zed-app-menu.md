## 3. 전체 메뉴 항목 대조표

항목 문구의 ASCII `...`와 단일 문자 `…`를 원본대로 구별했다. 아래 순서는 메뉴 정의 순서이며 Settings/Editor Layout 경로는 데이터상 그룹명을 나타낼 뿐, Windows에서는 부모 메뉴에 평탄하게 표시된다. 구분선 행은 Windows에 남는 그룹 경계의 대표 선언 위치를 기록한다. macOS 전용 행 제거로 인접하는 Zed의 97/100 및 104/111 구분선은 실제 sanitizer에서 합쳐진다. 중복·끝 구분선은 실제 렌더링의 정리 규칙을 적용한다.

판정은 우리 앱 요구에 대한 조사자 판단이다. 유지=새 코드로 우리 기능에 연결, 제외=미구현·미표시, 판단 필요=기능 범위 결정 전까지 최종 제안에서 제외. 원본 메뉴 action을 코드째 가져오라는 뜻이 아니다. `—`는 조사한 Windows 기본 키맵에 해당 action의 일반 binding을 찾지 못했다는 뜻이며 OS 예약키까지 없다는 주장은 아니다. 여러 키를 적은 칸은 유효 후보 목록이고 화면에서는 현재 context에서 하나를 resolve한다.
