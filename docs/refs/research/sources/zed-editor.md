# Zed 원문 편집기 화면과 동작 (ID 접두사 E-)

- 담당: scouter-opus · 조사일 2026-10-31 · 2차 보충 조사 (요건 4의 핵심)
- 소스 기준: zed-industries/zed 커밋 `14b7b0ef3764d62a85070c8b5ccea105a2ad3235`. 아래 링크는 모두 이 커밋에 고정했다. 표에서는 `Z/경로#L줄`로 줄여 쓰고, 전체 주소는 `https://github.com/zed-industries/zed/blob/14b7b0ef3764d62a85070c8b5ccea105a2ad3235/경로#L줄`이다.
- GPL 코드 원문은 옮기지 않았다. 값·이름·동작과 화면에 보이는 짧은 문구만 적었다.
- 키는 base_keymap=VSCode 적용 결과를 따른다. `linux/vscode.json` 덧씌움은 편집기 쪽에서 몇 개만 바꾸므로(zed-panes-keymap.md I-740~I-752), 이 문서의 키는 `default-windows.json` 값에 그 덧씌움을 반영한 것이다. 표기는 Zed 메뉴·툴팁 형식(`Ctrl-F`, L-219)을 쓴다.
- 치수는 논리 px(배율 100%)이고, 기준 설정은 `buffer_font_size` 15, `ui_font_size` 16(rem 16)이다.
- 기준 화면 두 장(`zed-reference.png`: Mocha 다크·최대화, `zed-reference-latte.png`: Latte 라이트·창 모드)은 **모두 마크다운 미리보기 탭이 활성**이라 원문 편집기 본문이 보이지 않는다. 그래서 이 문서의 편집기 시각 값은 소스 근거뿐이다. 화면으로 확인할 수 있는 것은 상태 표시줄 커서 위치("9:11", "1:1")와 탭 상태 정도다.

## 8. 확신 낮은 부분

- **편집기 본문 화면 근거가 없다:** 두 기준 화면 모두 미리보기 탭이 활성이라 거터·줄 번호·현재 줄·커서·스크롤바를 화면으로 대조할 수 없다. 모두 소스 값이다. 편집기 탭이 활성인 화면 캡처를 추가로 받으면 E-002~E-005의 px를 확정할 수 있다.
- **px 환산 (E-002, E-003, E-005):** 9px advance, descent 3~4px는 Lilex 15px에 대한 추정이다. 실제 값은 글꼴 메트릭(`ch_width`, `ch_advance`, `descent`)으로 계산해야 한다.
- **거터 왼쪽 여백 (E-003):** Zed 기본(3 ch)과 "Git·실행·중단점을 뺀 우리 앱"(1 ch) 가운데 무엇을 따를지는 결정이 필요하다. 기준 화면처럼 보이게 하려면 3 ch가 맞다.
- **접기 화살표 표시 시점 (E-008):** hover 때만 보인다는 것은 추정이다. element.rs의 fold indicator 렌더를 확인하지 않았다.
- **같은 텍스트 강조 색 (E-016):** 어떤 토큰을 쓰는지 찾지 못했다 (`editor_document_highlight_*` 계열로 추정).
- **커서 깜빡임과 포커스 (E-013):** 포커스가 없을 때 깜빡임을 멈추는 연결은 추정이다.
- **스크롤바 자동 숨김 (E-033):** Windows에서 `ScrollbarAutoHide`가 어떤 OS 설정을 읽는지 확인하지 않았다.
- **찾기 입력 상자 폭 (E-062):** flex 안에서 줄어드는 실제 폭은 계산하지 않았다.
- **브레드크럼 (E-038):** 경로 구분 기호, 구조(심볼) 표시 방식, 클릭 동작(Go to Symbol 열기로 추정)의 세부를 찾지 못했다. 렌더 함수 위치는 미확인이다.
- **TaskDialog 버튼 (E-080~E-085):** 버튼 순서가 Zed 배열 순서 그대로인지, 기본 버튼(Enter)이 첫 버튼인지, 인라인 코드 표기(`` `경로` ``)가 OS 창에서 백틱 그대로 보이는지는 미확인이다.
- **"1:1" 표시 (E-106):** Latte 화면은 미리보기 탭이 활성인데 상태 표시줄에 "1:1"이 보인다. 미리보기가 원문 편집기를 활성 편집기로 넘기는지, 같은 Pane의 다른 편집기 위치인지는 확인하지 못했다.
- **Latte 화면의 흐린 탭:** "Preview README.md"와 그 오른쪽 탭 제목이 다른 비활성 탭보다 흐리게 보인다. 탭 글자색 규칙은 탭 담당 문서(01-LAYOUT·zed-pickers-dialogs.md 5절)에서 확인할 일이다. 이 문서에서는 판단하지 않았다.
- **줄 번호:** 일부 링크의 줄 범위는 grep 결과로 잡은 근사치(±수 줄)다.
