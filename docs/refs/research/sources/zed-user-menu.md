## 5. 유지 항목만 남긴 최종 메뉴 구조 제안

판단: 계정·업데이트·확장·패널 배치 전환을 제거하고 아래 네 항목만 원래 순서로 남긴다. 네 항목은 원본에서도 연속이며 사이에 구분선이 없다. 원본의 계정/업데이트/조직/패널 배치/로그아웃 그룹이 전부 없어졌으므로 그 앞뒤 구분선도 함께 제거한다. 빈 구분선·메뉴 머리의 구분선·끝 구분선을 새로 남기지 않는다. 근거: [소스](https://github.com/zed-industries/zed/blob/14b7b0ef3764d62a85070c8b5ccea105a2ad3235/crates/title_bar/src/title_bar.rs#L1280-L1422).

```text
타이틀 바 오른쪽: [∨] [창 제어 버튼들]
                  │
                  ├─ Settings       Ctrl+,
                  ├─ Keymap         Ctrl+K → Ctrl+S
                  ├─ Themes…        Ctrl+K → Ctrl+T
                  └─ Icon Themes…

구분선: 없음
Sign In / Signing in… / avatar / 조직 이름 / 업데이트 점: 없음
∨ hover tooltip: 없음 (접근성 이름 User menu는 유지)
```
