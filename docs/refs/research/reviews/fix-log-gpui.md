## 일부만 반영한 지적

- 행 높이 (checker·sol B-01·agy B-3): 소스로 **26 = 24(`h_6`) + 2(ListItem 테두리)** 를 확인해 L-36 에 적었다. "24" 는 `h_6` 만, "25~26" 은 14 × 1.618 + 2 를 센 것이라 둘 다 일부만 센 값이다. 상태 표시줄 30 + 보정, 사이드바 푸터 높이의 같음 여부는 그대로 추정으로 남겼다.
- 사이드바 폭 (agy B-7): Zed 기본 300(소스), 두 기준 화면 모두 200(사용자 조정), 프로젝트 패널 기본 240 / Mocha 약 284 / Latte 약 215(화면마다 다름)로 구분했다. 우리 앱 초기값은 소스 기본값 300 / 240 으로 판단했다. 04 A-02 가 200 을 기본으로 쓰고 있으면 고쳐야 한다 → writer-tauri.
- 스크롤바 (sol A-02, agy A-6): 두께 6(편집기 15), 바깥 여백 4, 손잡이 최소 25 는 소스로 확인해 4.10절에 적었다. 표시·숨김 시점, 트랙 클릭, 바퀴 규칙은 자리.
- 텍스트 상태색 (agy A-3): 트리 항목(비선택 `text_muted`, 표시된 항목 `text`)과 탭 글자색은 소스로 확정했다. 상태 표시줄 커서 위치 글자색은 소스에서 못 찾아 관찰값(검토자 측정)으로만 L-307 에 적었다.
- 1px 구분선 3곳 (agy A-4): 타이틀 바 아래·상태 표시줄 위 선은 작업 영역 상자의 `border_t_1`·`border_b_1` 이 만든다는 것을 소스로 확인했다 (L-301). 지적의 "상태 표시줄 위쪽 선"은 상태 표시줄 자신의 테두리가 아니다. 상태 표시줄 자체 `border_b` 는 배경색이라 보이지 않는다 (L-304).
- 비활성 탭 (사용자 추가, Latte 화면): 편집기 탭과 마크다운 미리보기 탭의 글자색 규칙이 다르다는 것을 소스(`TabContentParams::text_color`)로 확정해 L-306 에 적었다.

## 3차 추가 (확장 세부 결정, ID 정의 규칙)

- **확장 세부 결정 반영:** 확장 관리 화면은 로컬 설치만 한다. 01 4.15·02 16절에서 온라인 전용 요소(설치 상태 토글 X-47, Install·Upgrade 버튼, Downloads, ⋯ 메뉴, 로딩 표시, 레지스트리 요청 X-52, 자동 설치·업데이트 X-42, 라이선스 검사 X-62)를 뺐다. 추가: "Install Extension…" 버튼(폴더·`.tar.gz`·`.zip` 로컬 설치, 판단), 설치 목록 정렬(이름 오름차순, 판단). "레지스트리 서버 주소" 남은 결정은 없어졌다. 끄기 기능 없음은 02 16 머리에 적었다.

ID 자체는 바꾸지 않았다.
